# @blotch/angular-lynx

Every export of the AngularLynx runtime, grouped by what it's for, with a link to its reference. Install it with `ng add @blotch/angular-lynx`.

```typescript
import {
  bootstrapApplication,
  provideRenderer,
  provideRouter,
  LYNX_ELEMENTS,
} from '@blotch/angular-lynx';
```
