# `<block>`

An invisible grouping element with no box of its own, like an element with `display: contents`. Its children lay out as if they were children of its parent.

<Go example="element-block" defaultFile="src/app/app.ts" />

## Usage

```typescript title="src/app/contact.ts"
import { Component, signal } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';

@Component({
  selector: 'app-contact',
  imports: [LYNX_ELEMENTS],
  template: `
    <view class="row">
      <block>
        <text>{{ name() }}</text>
        <text>{{ email() }}</text>
      </block>
    </view>
  `,
})
export class Contact {
  readonly name = signal('Ada');
  readonly email = signal('ada@example.com');
}
```

Import `LYNX_ELEMENTS` in your component (see [Elements](/api/angular-lynx/elements)).

Angular's `<ng-container>` also groups elements, and creates no element at all. Use `<block>` when you need a real element in the tree, such as a host for a directive.

## Attributes

None of its own. Layout and visual styles have no effect, because it has no box.

## Events

None.
