# `<blur-view>`

Blurs whatever is behind it, like CSS `backdrop-filter: blur()`, which Lynx doesn't support. On iOS 26 and on web it also draws Apple's Liquid Glass material. To blur an element's own content instead, use the `filter: blur()` style.

## Usage

```typescript title="src/app/now-playing.ts"
import { Component } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';

@Component({
  selector: 'app-now-playing',
  imports: [LYNX_ELEMENTS],
  template: `
    <view style="width: 100%; height: 300px;">
      <image
        src="https://example.com/cover.jpg"
        style="width: 100%; height: 100%;"
      />
      <blur-view
        blur-radius="20px"
        blur-effect="light"
        style="position: absolute; left: 16px; right: 16px; bottom: 16px; height: 64px; border-radius: 16px;"
      >
        <text>Now playing</text>
      </blur-view>
    </view>
  `,
})
export class NowPlaying {}
```

Import `LYNX_ELEMENTS` in your component (see [Elements](/api/angular-lynx/elements)).

:::warning
Needs [XElement](/guide/glossary#xelement) in custom native apps (see [Embedding](/guide/embedding/)).
:::

## Attributes

| Attribute                         | Type                                                                 | Default                       | Description                                                                                                                                                                                                                             |
| --------------------------------- | -------------------------------------------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `blur-radius`                     | `string`                                                             | `'0px'`                       | Strength of the blur, e.g. `'20px'`. Every platform supports it.                                                                                                                                                                        |
| `blur-effect`                     | `'light' \| 'extra-light' \| 'dark' \| 'glass' \| 'glass-container'` | `'light'`                     | The material: how bright the blur is, or Liquid Glass (`'glass'`, iOS 26 and later). A `'glass-container'` merges the glass `<blur-view>` elements inside it.                                                                           |
| `glass-style`                     | `'regular' \| 'clear'`                                               | `'regular'`                   | Glass variant: frosted, or clear.                                                                                                                                                                                                       |
| `glass-tint-color`                | `string`                                                             | `'transparent'`               | Color tint over the glass.                                                                                                                                                                                                              |
| `glass-interactive`               | `boolean`                                                            | `false`                       | iOS and web. The glass reacts to touches.                                                                                                                                                                                               |
| `spacing`                         | `number`                                                             | `0`                           | iOS and web. Inside a `'glass-container'`, glass shapes closer than this many px merge into one.                                                                                                                                        |
| `ios-user-interface-style`        | `'light' \| 'dark'`                                                  | —                             | iOS (Lynx 4.1 and later) and web. Forces a light or dark material.                                                                                                                                                                      |
| `blur-sampling`                   | `number`                                                             | `6`                           | Android only. Blurs a smaller copy of the background: higher is faster but softer.                                                                                                                                                      |
| `enable-auto-blur`                | `boolean`                                                            | `true`                        | Android only. Blurs again whenever the content behind changes.                                                                                                                                                                          |
| `android-capture-target`          | `string`                                                             | The page (set by AngularLynx) | Android only. `id`, without `#`, of the view whose pixels get blurred. That view needs `flatten="false"`. AngularLynx points it at the page so that a `<blur-view>` inside another one still works; `''` restores Android's own choice. |
| `experimental-update-blur-radius` | `boolean`                                                            | —                             | Android only, experimental. Switches how the blur is refreshed.                                                                                                                                                                         |

Plus the [common attributes](/api/elements/view#attributes), such as `id`, `class` and `style`.

## Events

None, apart from the [common events](/api/elements/view#events), such as `bindtap`.

## Platform support

| Platform | What you get                                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| iOS      | Blur, every material, and Liquid Glass on iOS 26 and later.                                                                                                                                     |
| Android  | Blur only. AngularLynx tints it to approximate the materials and glass; a `background-color` or `box-shadow` you set replaces the tint. Glass doesn't refract or merge.                         |
| Web      | AngularLynx draws the blur, the materials and the glass itself, the glass with WebGL, refracting the nearest ancestor that draws a background. Without WebGL, glass falls back to a plain blur. |

For glass that picks the right material on each platform and follows the user's accessibility settings, use the [Glass](/dolan/glass) UI component.
