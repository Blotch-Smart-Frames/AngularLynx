# `<svg>`

Draws SVG from a markup string or a URL. Unlike HTML, you can't write SVG tags in the template: pass the markup as text, and give the element a width and height.

<Go example="element-svg" defaultFile="src/app/app.ts" />

## Usage

```typescript title="src/app/dot.ts"
import { Component } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';

@Component({
  selector: 'app-dot',
  imports: [LYNX_ELEMENTS],
  template: `<svg [content]="icon" style="width: 24px; height: 24px;" />`,
})
export class Dot {
  readonly icon = `<svg viewBox="0 0 24 24" xmlns="http://www.w3.org/2000/svg">
    <circle cx="12" cy="12" r="10" fill="#dd0031" />
  </svg>`;
}
```

Import `LYNX_ELEMENTS` in your component (see [Elements](/api/angular-lynx/elements)).

:::warning
Needs [XElement](/guide/glossary#xelement) in custom native apps (see [Embedding](/guide/embedding/)).
:::

## Attributes

| Attribute       | Type     | Default | Description                                                                                                                                                                                                                                                                                                                                                            |
| --------------- | -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `content`       | `string` | —       | SVG markup to draw. It can't use CSS variables or the page's styles. Draw lines with `<path>`: `<line>` doesn't show on iOS and Android. Give the root `<svg>` `xmlns="http://www.w3.org/2000/svg"`: without it, the web preview draws nothing. AngularLynx removes `stroke-dasharray` values iOS can't parse, such as `none`, which would blank every SVG in the app. |
| `src`           | `string` | —       | URL of an SVG file. Use `src` or `content`, not both.                                                                                                                                                                                                                                                                                                                  |
| `current-color` | `string` | —       | iOS (Lynx 4.1 and later) and Android. The color `currentColor` stands for in the SVG. It doesn't override an explicit `fill` or `stroke`.                                                                                                                                                                                                                              |

Plus the [common attributes](/api/elements/view#attributes), such as `id`, `class` and `style`.

## Events

| Event      | `detail`                            | Description        |
| ---------- | ----------------------------------- | ------------------ |
| `bindload` | `{ width: number; height: number }` | The SVG was drawn. |

Plus the [common events](/api/elements/view#events), such as `bindtap`.
