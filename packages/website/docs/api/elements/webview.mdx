# `<webview>`

Shows a website or an HTML string inside your app, like an `<iframe>`. Use it for help pages, terms of service or sign-in pages. To embed another Lynx bundle, use [`<frame>`](/api/elements/frame).

<Go example="element-webview" defaultFile="src/app/app.ts" />

## Usage

```typescript title="src/app/help.ts"
import { Component, signal } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';

@Component({
  selector: 'app-help',
  imports: [LYNX_ELEMENTS],
  template: `
    @if (loading()) {
      <text>Loading…</text>
    }
    <webview
      src="https://angular.dev"
      style="width: 100%; height: 400px;"
      (bindload)="loading.set(false)"
    ></webview>
  `,
})
export class Help {
  readonly loading = signal(true);
}
```

Import `LYNX_ELEMENTS` in your component (see [Elements](/api/angular-lynx/elements)).

:::warning
Needs [XElement](/guide/glossary#xelement) in custom native apps (see [Embedding](/guide/embedding/)).
:::

## Attributes

**Clay** is a separate Lynx renderer used by Lynx's desktop apps. AngularLynx's iOS, Android and web builds don't use it, so you can ignore the Clay-only rows.

| Attribute           | Type       | Default     | Description                                                                                                                                                                                                      |
| ------------------- | ---------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src`               | `string`   | —           | URL to load. Changing it reloads the page. In the [web preview](/guide/glossary#web-preview), most sites show a broken page while `bindload` still fires: check URLs on a device, and use `html` in the browser. |
| `html`              | `string`   | —           | HTML to load. Ignored when `src` is set.                                                                                                                                                                         |
| `bounces`           | `boolean`  | `false`     | iOS only. Bounce at the edges.                                                                                                                                                                                   |
| `scroll-bar-enable` | `boolean`  | `false`     | iOS only. Shows the scroll bar.                                                                                                                                                                                  |
| `enable-debug`      | `boolean`  | `false`     | Lets you inspect the page with Chrome DevTools (Android) or Safari Web Inspector (iOS).                                                                                                                          |
| `webview-type`      | `string`   | `'default'` | iOS and Android. Picks a custom web view that the [host app](/guide/glossary#host-app) provides.                                                                                                                 |
| `params`            | `object`   | —           | iOS and Android. Options for that custom web view.                                                                                                                                                               |
| `initjs`            | `string`   | —           | Desktop (Clay) only. Script to run when the document is ready.                                                                                                                                                   |
| `cookies`           | `object[]` | —           | Clay only. Cookies to set before loading, each `{ name, value, domain?, path?, secure?, httpOnly?, sameSite }`.                                                                                                  |
| `use-osr`           | `boolean`  | `false`     | Clay only. Renders the page off screen.                                                                                                                                                                          |

Plus the [common attributes](/api/elements/view#attributes), such as `id`, `class` and `style`.

## Events

Read the payload from `$event.detail` (see [Handling taps and events](/guide/elements/event-handling)).

| Event                | `detail`                                  | Description                                 |
| -------------------- | ----------------------------------------- | ------------------------------------------- |
| `bindload`           | —                                         | The page finished loading.                  |
| `binderror`          | `{ errorCode: number; errorMsg: string }` | The page failed to load.                    |
| `bindmessage`        | `{ msg: string }`                         | The page sent a message to your app.        |
| `bindopenwindow`     | `{ url: string }`                         | Clay only. The page tried to open a window. |
| `bindlocationchange` | `{ url: string }`                         | Clay only. The page navigated to `url`.     |

Plus the [common events](/api/elements/view#events), such as `bindtap`.

## Methods

These **UI methods** ([Glossary](/guide/glossary#ui-method)) control the page. Call them with `invoke()` on the element (see [Call element methods](/guide/selector-query)).

| Method                                                               | Parameters         | Description                                                     |
| -------------------------------------------------------------------- | ------------------ | --------------------------------------------------------------- |
| `reload`                                                             | —                  | Reloads the page.                                               |
| `eval`                                                               | `{ func: string }` | Calls a JavaScript function in the page, e.g. `'greet("Ada")'`. |
| `cookies.get`, `cookies.set`, `cookies.remove`, `cookies.flushStore` | Varies             | Clay only. Read and change the web view's cookies.              |

```typescript
import { Component, ElementRef, viewChild } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';

@Component({
  selector: 'app-help-page',
  imports: [LYNX_ELEMENTS],
  template: `
    <webview
      #help
      src="https://angular.dev"
      style="width: 100%; height: 400px;"
    ></webview>
    <view (bindtap)="reload()"><text>Reload</text></view>
  `,
})
export class HelpPage {
  readonly help = viewChild.required('help', { read: ElementRef });

  reload(): void {
    this.help().nativeElement.invoke?.('reload');
  }
}
```
