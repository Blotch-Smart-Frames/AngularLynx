## Main-thread scripts

Code that runs on the [main thread](/guide/glossary#main-thread), right inside native events. Read [Main-thread scripts](/guide/main-thread/) first.

| Page                                                        | What it covers                                   |
| ----------------------------------------------------------- | ------------------------------------------------ |
| [`mainThreadFn`](/api/main-thread/main-thread-fn)           | Define a function that runs on the main thread   |
| [`LynxMainThreadEvent`](/api/main-thread/main-thread-event) | Bind main-thread functions to native events      |
| [`MainThreadRef`](/api/main-thread/main-thread-ref)         | Keep a value between main-thread script calls    |
| [`LynxMainThread`](/api/main-thread/main-thread-service)    | Call a main-thread function from Angular code    |
| [`backgroundFn`](/api/main-thread/background-fn)            | Call background-thread code from the main thread |

## Elements

The native elements your templates use instead of HTML. See [Elements and layout](/guide/elements/) for how they compare with HTML.

| Element                                                    | Use it for                                           |
| ---------------------------------------------------------- | ---------------------------------------------------- |
| [`<view>`](/api/elements/view)                             | Layout and grouping, like `<div>`                    |
| [`<text>`](/api/elements/text)                             | All visible text                                     |
| [`<image>`](/api/elements/image)                           | Local and remote images                              |
| [`<scroll-view>`](/api/elements/scroll-view)               | A scrolling area                                     |
| [`<list>`](/api/elements/list)                             | Long lists that render only the visible rows         |
| [`<refresh>`](/api/elements/refresh)                       | Pull to refresh                                      |
| [`<scroll-coordinator>`](/api/elements/scroll-coordinator) | Collapsing headers and sticky toolbars               |
| [`<viewpager>`](/api/elements/viewpager)                   | Pages you swipe between                              |
| [`<input>`](/api/elements/input)                           | Single-line text input                               |
| [`<textarea>`](/api/elements/textarea)                     | Multi-line text input                                |
| [`<overlay>`](/api/elements/overlay)                       | Content above the page, such as dialogs              |
| [`<frame>`](/api/elements/frame)                           | Another Lynx bundle inside this page                 |
| [`<block>`](/api/elements/block)                           | Grouping without a layout box, like `<ng-container>` |
| [`<svg>`](/api/elements/svg)                               | SVG graphics                                         |
| [`<blur-view>`](/api/elements/blur-view)                   | Frosted, blurred backgrounds                         |
| [`<video>`](/api/elements/video)                           | Video playback                                       |
| [`<webview>`](/api/elements/webview)                       | Web pages inside your app                            |
| [`<title-bar-view>`](/api/elements/title-bar-view)         | The draggable area of a desktop window's title bar   |
| [`<cover-view>`](/api/elements/cover-view)                 | Content that draws above a desktop `<webview>`       |
