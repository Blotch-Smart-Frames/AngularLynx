# Event reference

Every event [`fireEvent`](/api/testing-library/#fireeventelement-event) has a method for, and the template binding each one runs.

```typescript
fireEvent.tap(element); // runs (bindtap)
fireEvent.tap(element, { eventType: 'catchEvent' }); // runs (catchtap)
fireEvent.input(element, { detail: { value: 'hello' } }); // $event.detail.value
```

Each method takes the element and an optional `init` object. To reach a `(catch*)` handler instead of a `(bind*)` one, pass `{ eventType: 'catchEvent' }`.

## Touch

| Method                  | Binding             |
| ----------------------- | ------------------- |
| `fireEvent.tap`         | `(bindtap)`         |
| `fireEvent.longpress`   | `(bindlongpress)`   |
| `fireEvent.longtap`     | `(bindlongtap)`     |
| `fireEvent.touchstart`  | `(bindtouchstart)`  |
| `fireEvent.touchmove`   | `(bindtouchmove)`   |
| `fireEvent.touchend`    | `(bindtouchend)`    |
| `fireEvent.touchcancel` | `(bindtouchcancel)` |

## Other events

For an event without a method, create it yourself. Its type is the binding's event type and the event name, joined by a colon:

```typescript
fireEvent(element, new Event('bindEvent:change')); // runs (bindchange)
```
