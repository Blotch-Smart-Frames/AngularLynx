# Accordion

A stack of sections that expand when tapped, one at a time or several at once.

<Go example="ui-accordion" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add accordion
```

```typescript
import {
  UiAccordion,
  UiAccordionContent,
  UiAccordionItem,
  UiAccordionTrigger,
} from '../components/ui/accordion';
```

## Usage

```typescript title="src/app/app.ts"
import { Component } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';
import {
  UiAccordion,
  UiAccordionContent,
  UiAccordionItem,
  UiAccordionTrigger,
} from '../components/ui/accordion';

@Component({
  selector: 'app-root',
  imports: [
    LYNX_ELEMENTS,
    UiAccordion,
    UiAccordionItem,
    UiAccordionTrigger,
    UiAccordionContent,
  ],
  template: `
    <ui-accordion>
      <ui-accordion-item value="shipping">
        <ui-accordion-trigger>
          How long does shipping take?
        </ui-accordion-trigger>
        <ui-accordion-content>
          <text class="text-sm text-muted-foreground">Three to five days.</text>
        </ui-accordion-content>
      </ui-accordion-item>
      <ui-accordion-item value="returns">
        <ui-accordion-trigger>Can I return an item?</ui-accordion-trigger>
        <ui-accordion-content>
          <text class="text-sm text-muted-foreground">
            Yes, within 30 days.
          </text>
        </ui-accordion-content>
      </ui-accordion-item>
    </ui-accordion>
  `,
})
export class App {}
```

- Each item needs a unique `value`. All items start closed.
- The trigger wraps its content in `<text>` and adds an arrow, so pass plain text.
- Content shows only while its item is open. It slides and fades in as the item opens.

### Several open at once

```angular-html
<ui-accordion type="multiple">…</ui-accordion>
```

With the default `single`, opening an item closes the others.

### Control from code

```typescript title="src/app/faq.ts"
import { Component, viewChild } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';
import {
  UiAccordion,
  UiAccordionContent,
  UiAccordionItem,
  UiAccordionTrigger,
} from '../components/ui/accordion';

@Component({
  selector: 'app-faq',
  imports: [
    LYNX_ELEMENTS,
    UiAccordion,
    UiAccordionItem,
    UiAccordionTrigger,
    UiAccordionContent,
  ],
  template: `
    <text class="text-sm text-primary" (bindtap)="showReturns()">
      Read the returns policy
    </text>
    <ui-accordion>
      <ui-accordion-item value="returns">
        <ui-accordion-trigger>Can I return an item?</ui-accordion-trigger>
        <ui-accordion-content>
          <text class="text-sm text-muted-foreground">
            Yes, within 30 days.
          </text>
        </ui-accordion-content>
      </ui-accordion-item>
    </ui-accordion>
  `,
})
export class Faq {
  readonly faq = viewChild.required(UiAccordion);

  protected showReturns(): void {
    if (!this.faq().isExpanded('returns')) {
      this.faq().toggle('returns');
    }
  }
}
```

`UiAccordion` has two public methods: `toggle(value)` opens or closes an item, and `isExpanded(value)` says whether it's open. The open values are in its `expandedItems` signal, a `Set<string>`.

## API

### UiAccordion

| Input   | Type                     | Default    | Description                                |
| ------- | ------------------------ | ---------- | ------------------------------------------ |
| `type`  | `'single' \| 'multiple'` | `'single'` | Whether opening an item closes the others. |
| `class` | `string`                 | `''`       | Extra Tailwind classes for the container.  |

No outputs.

### UiAccordionItem

| Input   | Type     | Default  | Description                                |
| ------- | -------- | -------- | ------------------------------------------ |
| `value` | `string` | Required | Identifies the item. Unique per accordion. |
| `class` | `string` | `''`     | Extra Tailwind classes for the item.       |

No outputs.

All other sub-components (`UiAccordionTrigger`, `UiAccordionContent`) accept `class`.
