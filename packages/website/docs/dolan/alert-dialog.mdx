# Alert Dialog

A modal dialog that requires user acknowledgement. Unlike [Dialog](/dolan/dialog), tapping the backdrop does **not** dismiss an alert dialog -- the user must explicitly choose an action.

<Go example="ui-alert-dialog" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add alert-dialog
```

```typescript
import {
  UiAlertDialog,
  UiAlertDialogHeader,
  UiAlertDialogTitle,
  UiAlertDialogDescription,
  UiAlertDialogFooter,
} from '@/components/ui/alert-dialog';
```

## Usage

```typescript
import { Component, signal } from '@angular/core';
import {
  UiAlertDialog,
  UiAlertDialogHeader,
  UiAlertDialogTitle,
  UiAlertDialogDescription,
  UiAlertDialogFooter,
} from '@/components/ui/alert-dialog';
import { UiButton } from '@/components/ui/button';

@Component({
  imports: [
    UiAlertDialog,
    UiAlertDialogHeader,
    UiAlertDialogTitle,
    UiAlertDialogDescription,
    UiAlertDialogFooter,
    UiButton,
  ],
  template: `
    <ui-button (pressed)="open.set(true)">Delete</ui-button>

    <ui-alert-dialog [(open)]="open">
      <ui-alert-dialog-header>
        <ui-alert-dialog-title>Are you sure?</ui-alert-dialog-title>
        <ui-alert-dialog-description>
          This action cannot be undone.
        </ui-alert-dialog-description>
      </ui-alert-dialog-header>
      <ui-alert-dialog-footer>
        <ui-button variant="outline" (pressed)="open.set(false)">
          Cancel
        </ui-button>
        <ui-button variant="destructive" (pressed)="onConfirm()">
          Continue
        </ui-button>
      </ui-alert-dialog-footer>
    </ui-alert-dialog>
  `,
})
export class Example {
  open = signal(false);

  onConfirm(): void {
    this.open.set(false);
  }
}
```

## API

### UiAlertDialog

| Input / Output | Type             | Default | Description                                 |
| -------------- | ---------------- | ------- | ------------------------------------------- |
| `open`         | `model<boolean>` | `false` | Two-way binding that controls visibility    |
| `class`        | `string`         | `''`    | Additional CSS classes for the dialog panel |
| `closed`       | `output<void>`   | --      | Emitted after the close animation completes |

### UiAlertDialogHeader

| Input   | Type     | Default | Description            |

| `class` | `string` | `''`    | Additional CSS classes |
