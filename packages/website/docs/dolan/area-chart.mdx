# Area Chart

Plot one series as a line with the region down to a baseline filled in. It's a preset of [`<ui-chart>`](/dolan/chart): it builds a [TanStack Charts](https://tanstack.com/charts) definition from its inputs, so it has the same touch tooltip, screen reader support, pan and zoom, and dark mode.

<Go example="ui-area-chart" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add area-chart
```

:::tip
The area chart depends on [`chart`](/dolan/chart), which is added automatically, along with the npm packages it imports: `@tanstack/charts` and `d3-shape`.
:::

```typescript
import { UiAreaChart } from '@/components/ui/area-chart';
```

## Usage

Pass an array of `{ x, y }` points, both numbers. The chart fits rounded axis ranges to the data and fills down to `y = 0`.

```angular-html
<ui-area-chart [data]="revenue" label="Monthly revenue" />
```

```typescript
revenue = [
  { x: 1, y: 12 },
  { x: 2, y: 19 },
  { x: 3, y: 15 },
  { x: 4, y: 25 },
];
```

Touch the chart to see a point's values in a tooltip, and tap to pin it. Set `label` so a screen reader can say what the chart shows.

### Color and fill opacity

`color` sets the line, the dots and the fill. `fillOpacity` sets how solid the fill is (default `0.2`). A theme color such as `var(--chart-2)` switches with [dark mode](/dolan/chart#dark-mode); a fixed color stays the same.

```angular-html
<ui-area-chart [data]="downloads" color="var(--chart-2)" [fillOpacity]="0.3" />
```

Set `showDots` to `false` to hide the dots.

### Baseline

`baseline` is the y value the fill reaches to (default `0`), and the y axis always includes it. Where the data dips below the baseline, the fill reaches up to it instead.

```angular-html
<ui-area-chart [data]="delta" [baseline]="0" />
```

### Smooth curve

Set `smooth` to curve the line and the fill through the points instead of drawing straight segments.

```angular-html
<ui-area-chart [data]="revenue" [smooth]="true" />
```

The curve is monotone (d3's `curveMonotoneX`): it never overshoots the data, so the fill doesn't bulge past a peak.

### Label the axes

`xAxisLabel` and `yAxisLabel` add axis titles. Horizontal gridlines are on by default; `showGrid` turns them off and `showXGrid` adds vertical ones.

```angular-html
<ui-area-chart
  [data]="revenue"
  xAxisLabel="Month"
  yAxisLabel="Revenue ($k)"
  [showXGrid]="true"
/>
```

`xTickFormat` and `yTickFormat` turn tick values into labels, and `tickCount` sets roughly how many ticks each axis gets.

### Fix the axis range

Pass `yMin` and `yMax` (or `xMin` and `xMax`) to fix an axis bound instead of fitting the data.

```angular-html
<ui-area-chart [data]="revenue" [yMax]="40" />
```

### Pad the plot edges

`padding` insets the plot, each side as a fraction (`0` to `1`) of its size.

```angular-html
<ui-area-chart [data]="revenue" [padding]="{ left: 0.05, right: 0.05 }" />
```

### Size

The chart fills its container's width and is 200px tall. Set `height` for a different height, and `width` for a fixed width, both in px.

### Handle taps

`pointTap` emits the tapped `{ x, y }` point. Set `tooltip` to `false` to turn the tooltip off.

```angular-html
<ui-area-chart [data]="revenue" (pointTap)="onPointTap($event)" />
```

### Pan and zoom

Set `zoomable` to let users drag to pan, with **+**, **−** and **1:1** buttons.

```angular-html
<ui-area-chart [data]="revenue" [zoomable]="true" zoomAxes="x" />
```

See [Pan and zoom](/dolan/chart#pan-and-zoom) on the Chart page for how it behaves. To zoom from your own controls, call `zoomIn()`, `zoomOut()` or `resetZoom()` on the component.

## Several series, overlays and other marks

The preset draws one series. For several areas, stacked areas, or other marks, build a definition with TanStack's `areaY` and render it with [`<ui-chart>`](/dolan/chart#several-series). You can start from this preset's definition to keep its axes and styling:

```typescript
import { defineChart, ruleY } from '@tanstack/charts/universal';
import { areaChartDefinition } from '@/components/ui/area-chart';

const base = areaChartDefinition({ data: revenue, smooth: true });

const withAverage = defineChart({
  ...base,
  marks: [
    ...base.marks,
    ruleY([average], {
      stroke: 'var(--muted-foreground)',
      strokeDasharray: '4 4',
    }),
  ],
});
```

```angular-html
<ui-chart [definition]="withAverage" label="Revenue and its average" />
```

## API

### UiAreaChart

| Input              | Type                            | Default                    | Description                                                   |
| ------------------ | ------------------------------- | -------------------------- | ------------------------------------------------------------- |
| `data`             | `XYDatum[]`                     | _required_                 | Points to plot, each `{ x, y }`                               |
| `color`            | `string`                        | `'var(--primary)'`         | Line, dot and fill color (any CSS color)                      |
| `fillOpacity`      | `number`                        | `0.2`                      | Opacity of the fill, `0`–`1`                                  |
| `baseline`         | `number`                        | `0`                        | Y value the fill reaches to; always in view                   |
| `strokeWidth`      | `number`                        | `2`                        | Line thickness in px                                          |
| `dotRadius`        | `number`                        | `3`                        | Dot radius in px                                              |
| `showDots`         | `boolean`                       | `true`                     | Draw a dot at each point                                      |
| `smooth`           | `boolean`                       | `false`                    | Curve the line and fill (monotone)                            |
| `width`            | `number`                        | _fills container_          | Fixed width in px                                             |
| `height`           | `number`                        | `200`                      | Height in px                                                  |
| `tickCount`        | `number`                        | `5`                        | Target number of ticks per axis                               |
| `showGrid`         | `boolean`                       | `true`                     | Horizontal gridlines at the y ticks                           |
| `showXGrid`        | `boolean`                       | `false`                    | Vertical gridlines at the x ticks                             |
| `xAxisLabel`       | `string`                        | `''`                       | X-axis title                                                  |
| `yAxisLabel`       | `string`                        | `''`                       | Y-axis title                                                  |
| `padding`          | `ChartPadding`                  | `{}`                       | Inner inset, each side a `0`–`1` fraction of the plot         |
| `xMin`             | `number`                        | _auto_                     | Fixed x-axis lower bound                                      |
| `xMax`             | `number`                        | _auto_                     | Fixed x-axis upper bound                                      |
| `yMin`             | `number`                        | _auto_                     | Fixed y-axis lower bound                                      |
| `yMax`             | `number`                        | _auto_                     | Fixed y-axis upper bound                                      |
| `xTickFormat`      | `(value: number) => string`     | _auto_                     | Formats x-axis tick labels                                    |
| `yTickFormat`      | `(value: number) => string`     | _auto_                     | Formats y-axis tick labels                                    |
| `tooltip`          | `boolean`                       | `true`                     | Show a tooltip for the touched point; a tap pins it           |
| `label`            | `string`                        | `'Chart'`                  | What a screen reader announces for the chart                  |
| `colorScheme`      | `'light' \| 'dark' \| 'system'` | _from `provideChartTheme`_ | Light or dark colors; see [Dark mode](/dolan/chart#dark-mode) |
| `zoomable`         | `boolean`                       | `false`                    | Drag to pan, with zoom buttons                                |
| `zoomAxes`         | `'x' \| 'y' \| 'xy'`            | `'xy'`                     | Which axes pan and zoom                                       |
| `showZoomControls` | `boolean`                       | `true`                     | Show the +/−/1:1 buttons when zoomable                        |
| `minZoom`          | `number`                        | `1`                        | Smallest zoom; `1` shows all the data                         |
| `maxZoom`          | `number`                        | `8`                        | Largest zoom                                                  |
| `zoomStep`         | `number`                        | `1.4`                      | Zoom factor per button press                                  |
| `class`            | `string`                        | `''`                       | Additional CSS classes                                        |

| Output     | Type      | Description                     |
| ---------- | --------- | ------------------------------- |
| `pointTap` | `XYDatum` | Emits the point that was tapped |

| Method        | Description              |
| ------------- | ------------------------ |
| `zoomIn()`    | Zooms in by `zoomStep`   |
| `zoomOut()`   | Zooms out by `zoomStep`  |
| `resetZoom()` | Shows all the data again |

`XYDatum` is `{ x: number; y: number }` and `ChartPadding` is `{ top?, right?, bottom?, left? }`, each a fraction (`0`–`1`) of the plot's size, with omitted sides `0`. Both are exported from `@/components/ui/chart`.

### areaChartDefinition

`areaChartDefinition(options: AreaChartOptions)` returns the TanStack definition `<ui-area-chart>` renders: an `areaY` fill, a `lineY` on top, and `dot` marks. The options are the inputs that shape the chart, with the same defaults: `data`, `color`, `fillOpacity`, `baseline`, `strokeWidth`, `dotRadius`, `showDots`, `smooth`, `tickCount`, `showGrid`, `showXGrid`, `xAxisLabel`, `yAxisLabel`, `padding`, `xMin`, `xMax`, `yMin`, `yMax`, `xTickFormat`, `yTickFormat` and `tooltip`. Size, label and zoom are inputs of `<ui-chart>` instead.
