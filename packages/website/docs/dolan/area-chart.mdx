# Area Chart

Plot a series as a line with the region beneath it filled — drawn entirely from Lynx views, no SVG or canvas. It reuses the [Line Chart](/dolan/line-chart)'s line on top of a translucent fill, both built on the same **cartesian chart base**.

<Go example="ui-area-chart" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add area-chart
```

:::tip
The base **`cartesian-chart`** and **`line-chart`** (whose line series the fill sits under) are dependencies and install automatically.
:::

```typescript
import { UiAreaChart } from '@/components/ui/area-chart';
```

## Usage

Pass an array of `{ x, y }` points. The wrapper picks rounded axis ranges for you and fills down to `y = 0`.

```angular-html
<ui-area-chart [data]="revenue" [width]="280" [height]="180" />
```

```typescript
revenue = [
  { x: 1, y: 12 },
  { x: 2, y: 19 },
  { x: 3, y: 15 },
  { x: 4, y: 25 },
];
```

### Color and fill opacity

`color` sets the line and dots; `fillOpacity` controls how solid the fill reads (default `0.2`).

```angular-html
<ui-area-chart
  [data]="downloads"
  [color]="'rgba(59, 130, 246, 1)'"
  [fillOpacity]="0.25"
/>
```

### Baseline

`baseline` is the y-value the fill descends to (default `0`). With negative data, the fill straddles the baseline — above it where the line is higher, below it where the line dips under.

```angular-html
<ui-area-chart [data]="delta" [baseline]="0" />
```

### Smooth curve

Set `smooth` to curve both the fill and the line on top through the points, instead of straight segments.

```angular-html
<ui-area-chart [data]="revenue" [smooth]="true" />
```

The curve is a **monotone cubic** (like D3's `curveMonotoneX`): it never overshoots, so the fill never bulges past a peak or dips below the baseline.

### Label the axes

Set `xAxisLabel` / `yAxisLabel` for axis titles. `showXGrid` adds vertical gridlines.

```angular-html
<ui-area-chart
  [data]="revenue"
  xAxisLabel="Month"
  yAxisLabel="Revenue ($k)"
  [showXGrid]="true"
/>
```

### Fix the axis range

Pass `yMin` / `yMax` (or `xMin` / `xMax`) to pin an axis bound instead of fitting the data. The `baseline` is always folded in, so the fill's base is never clipped.

```angular-html
<ui-area-chart [data]="revenue" [yMax]="40" />
```

### Pad the plot edges

`padding` insets the plotted area, each side a fraction (`0`–`1`) of the plot size.

```angular-html
<ui-area-chart [data]="revenue" [padding]="{ left: 0.05, right: 0.05 }" />
```

### Multiple series

For more than one area, use the base `<ui-cartesian-chart>` with one `<ui-area-series>` per series. They share the axes, so they line up, and their translucent fills layer cleanly where they overlap.

```angular-html
<ui-cartesian-chart
  [xDomain]="[1, 6]"
  [yDomain]="[0, 40]"
  [xTicks]="[1, 2, 3, 4, 5, 6]"
  [yTicks]="[0, 10, 20, 30, 40]"
  [width]="280"
  [height]="180"
>
  <ui-area-series [data]="thisYear" [color]="'rgba(59, 130, 246, 1)'" />
  <ui-area-series [data]="lastYear" [color]="'rgba(34, 197, 94, 1)'" />
</ui-cartesian-chart>
```

### Handle taps

`pointTap` emits the tapped `{ x, y }` point.

```angular-html
<ui-area-chart [data]="revenue" (pointTap)="onPointTap($event)" />
```

:::info Why explicit `width` and `height`?
Lynx has no filled-polygon primitive, so the fill is rasterized into thin vertical views sized in **pixels** — hence the explicit `width`/`height` instead of stretch-to-fit. The line on top is drawn as rotated views, same as the [Line Chart](/dolan/line-chart).
:::

### Pan and zoom

Set `zoomable` for pinch-to-zoom and drag-to-pan, with on-screen `+` / `−` / `1:1` controls. The axes and gridlines update live as you zoom. Off by default.

```angular-html
<ui-area-chart [data]="revenue" [zoomable]="true" />
```

See [Pan and zoom](/dolan/line-chart#pan-and-zoom) for the shared options (`zoomAxes`, `minZoom`, `maxZoom`) and the `zoomIn()` / `zoomOut()` / `resetZoom()` methods.

## API

### UiAreaChart

The single-series convenience wrapper. Auto-computes the axes from `data` and the `baseline`.

| Input              | Type                        | Default            | Description                               |
| ------------------ | --------------------------- | ------------------ | ----------------------------------------- |
| `data`             | `ChartPoint[]`              | _required_         | Points to plot, each `{ x, y }`           |
| `color`            | `string`                    | `'var(--primary)'` | Line and dot color (any CSS color)        |
| `width`            | `number`                    | `320`              | Chart width in px                         |
| `height`           | `number`                    | `200`              | Chart height in px                        |
| `fillOpacity`      | `number`                    | `0.2`              | Opacity of the filled region              |
| `baseline`         | `number`                    | `0`                | Y-value the fill descends to              |
| `tickCount`        | `number`                    | `5`                | Target number of axis ticks               |
| `strokeWidth`      | `number`                    | `2`                | Line thickness in px                      |
| `dotRadius`        | `number`                    | `3`                | Data point radius in px                   |
| `showDots`         | `boolean`                   | `true`             | Draw a dot at each point                  |
| `smooth`           | `boolean`                   | `false`            | Curve the fill and line (monotone cubic)  |
| `showXGrid`        | `boolean`                   | `false`            | Draw vertical gridlines at x ticks        |
| `xAxisLabel`       | `string`                    | `''`               | X-axis title                              |
| `yAxisLabel`       | `string`                    | `''`               | Y-axis title                              |
| `padding`          | `ChartPadding`              | `{}`               | Inner inset, each side a `0`–`1` fraction |
| `xMin`             | `number`                    | _auto_             | Force x-axis lower bound                  |
| `xMax`             | `number`                    | _auto_             | Force x-axis upper bound                  |
| `yMin`             | `number`                    | _auto_             | Force y-axis lower bound                  |
| `yMax`             | `number`                    | _auto_             | Force y-axis upper bound                  |
| `xTickFormat`      | `(value: number) => string` | rounds to 2 dp     | Formats x-axis labels                     |
| `yTickFormat`      | `(value: number) => string` | rounds to 2 dp     | Formats y-axis labels                     |
| `zoomable`         | `boolean`                   | `false`            | Enable pinch/drag zoom + controls         |
| `zoomAxes`         | `'x' \| 'y' \| 'xy'`        | `'xy'`             | Which axes zoom/pan affect                |
| `showZoomControls` | `boolean`                   | `true`             | Show the +/−/1:1 controls when zoomable   |
| `minZoom`          | `number`                    | `1`                | Lower zoom bound (1 = fit all data)       |
| `maxZoom`          | `number`                    | `8`                | Upper zoom bound                          |
| `zoomStep`         | `number`                    | `1.4`              | Zoom factor per +/− control press         |
| `class`            | `string`                    | `''`               | Additional CSS classes                    |

| Output     | Type         | Description                          |
| ---------- | ------------ | ------------------------------------ |
| `pointTap` | `ChartPoint` | Emits the point when a dot is tapped |

### UiAreaSeries

One filled area inside a `<ui-cartesian-chart>`. Reads the shared axes from the chart and reuses `UiLineSeries` for the line on top.

| Input         | Type           | Default            | Description                              |
| ------------- | -------------- | ------------------ | ---------------------------------------- |
| `data`        | `ChartPoint[]` | _required_         | Points to plot, each `{ x, y }`          |
| `color`       | `string`       | `'var(--primary)'` | Line and dot color                       |
| `fillOpacity` | `number`       | `0.2`              | Opacity of the filled region             |
| `baseline`    | `number`       | `0`                | Y-value the fill descends to             |
| `strokeWidth` | `number`       | `2`                | Line thickness in px                     |
| `dotRadius`   | `number`       | `3`                | Data point radius in px                  |
| `showDots`    | `boolean`      | `true`             | Draw a dot at each point                 |
| `smooth`      | `boolean`      | `false`            | Curve the fill and line (monotone cubic) |
| `class`       | `string`       | `''`               | Additional CSS classes                   |

| Output     | Type         | Description                          |
| ---------- | ------------ | ------------------------------------ |
| `pointTap` | `ChartPoint` | Emits the point when a dot is tapped |

The x/y axes come from the surrounding [`UiCartesianChart`](/dolan/line-chart#uicartesianchart) — see the Line Chart page for its inputs.
