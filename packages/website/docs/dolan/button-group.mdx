# Button Group

A row or column of connected buttons that reads as one toolbar, where each button runs its own action.

<Go example="ui-button-group" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add button-group
```

```typescript
import {
  UiButtonGroup,
  UiButtonGroupItem,
} from '../components/ui/button-group';
```

Button Group imports `class-variance-authority` (see [Installation](/dolan/#installation)).

## Usage

```typescript title="src/app/app.ts"
import { Component } from '@angular/core';
import {
  UiButtonGroup,
  UiButtonGroupItem,
} from '../components/ui/button-group';

@Component({
  selector: 'app-root',
  imports: [UiButtonGroup, UiButtonGroupItem],
  template: `
    <ui-button-group>
      <ui-button-group-item (pressed)="copy()">Copy</ui-button-group-item>
      <ui-button-group-item (pressed)="paste()">Paste</ui-button-group-item>
    </ui-button-group>
  `,
})
export class App {
  protected copy(): void {}
  protected paste(): void {}
}
```

- The group sets the look of every item. Each item emits its own `pressed`.
- Nothing stays selected. For buttons that stay on, use a toggle group from [Toggle](/dolan/toggle).
- The group hugs its items. Add `class="w-full"` to stretch it.

### Variants

```angular-html
<ui-button-group variant="default">…</ui-button-group>
<ui-button-group variant="outline">…</ui-button-group>
```

`default` fills the items with the secondary color. `outline` uses the background color inside a border.

### Sizes

```angular-html
<ui-button-group size="sm">…</ui-button-group>
<ui-button-group size="default">…</ui-button-group>
<ui-button-group size="lg">…</ui-button-group>
```

### Vertical

```angular-html
<ui-button-group orientation="vertical" variant="outline">
  <ui-button-group-item (pressed)="openProfile()">Profile</ui-button-group-item>
  <ui-button-group-item (pressed)="openSettings()">
    Settings
  </ui-button-group-item>
</ui-button-group>
```

### Disabled

```angular-html
<ui-button-group [disabled]="true">…</ui-button-group>

<ui-button-group>
  <ui-button-group-item (pressed)="undo()">Undo</ui-button-group-item>
  <ui-button-group-item [disabled]="true">Redo</ui-button-group-item>
</ui-button-group>
```

Disable the whole group, or one item. A disabled item dims and doesn't emit `pressed`.

## API

### UiButtonGroup

| Input         | Type                         | Default        | Description                              |
| ------------- | ---------------------------- | -------------- | ---------------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Lays the items out in a row or a column. |
| `variant`     | `'default' \| 'outline'`     | `'default'`    | Visual style of every item.              |
| `size`        | `'default' \| 'sm' \| 'lg'`  | `'default'`    | Height and padding of every item.        |
| `disabled`    | `boolean`                    | `false`        | Disables every item.                     |
| `class`       | `string`                     | `''`           | Extra Tailwind classes for the group.    |

No outputs.

### UiButtonGroupItem

| Input      | Type      | Default | Description                          |
| ---------- | --------- | ------- | ------------------------------------ |
| `disabled` | `boolean` | `false` | Disables this item only.             |
| `class`    | `string`  | `''`    | Extra Tailwind classes for the item. |

| Output    | Type   | Description                                         |
| --------- | ------ | --------------------------------------------------- |
| `pressed` | `void` | Emits on tap, unless the item or group is disabled. |

The file also exports `buttonGroupItemVariants` and the `ButtonGroupVariant`, `ButtonGroupSize` and `ButtonGroupOrientation` types.
