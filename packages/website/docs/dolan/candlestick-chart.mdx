# Candlestick Chart

Plot prices over time as candles, each showing a period's open, high, low and close, with a touch tooltip, pan and zoom, and dark mode built in.

<Go example="ui-candlestick-chart" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add candlestick-chart
```

```typescript
import { UiCandlestickChart } from '../components/ui/candlestick-chart';
```

This also adds [Chart](/dolan/chart), which draws the preset, and installs the npm packages `@tanstack/charts` and `d3-shape`.

## Usage

```typescript
import { Component } from '@angular/core';
import { UiCandlestickChart } from '../components/ui/candlestick-chart';

@Component({
  selector: 'app-share-price',
  imports: [UiCandlestickChart],
  template: `<ui-candlestick-chart [data]="prices" label="Share price" />`,
})
export class SharePrice {
  protected readonly prices = [
    { x: 1, open: 100, high: 108, low: 98, close: 106 },
    { x: 2, open: 106, high: 110, low: 103, close: 104 },
    { x: 3, open: 104, high: 105, low: 96, close: 98 },
    { x: 4, open: 98, high: 102, low: 95, close: 101 },
  ];
}
```

- `data` is an array of `{ x, open, high, low, close }` items, all numbers. `x` is the period, such as a session index.
- Each candle has a thin **wick** from low to high and a wider **body** from open to close.
- The y axis fits the lowest low to the highest high, with room for the candles at each end.
- Touch a candle to see its four prices in a tooltip. Tap to pin it. Set `label` so a screen reader can say what the chart shows.

## Customize

### Colors

`upColor` colors candles that closed at or above their open (default green). `downColor` colors those that closed below (default red).

```angular-html
<ui-candlestick-chart
  [data]="prices"
  upColor="rgba(20, 184, 166, 1)"
  downColor="rgba(244, 63, 94, 1)"
/>
```

### Shape

`bodyWidthRatio` sets how much of its slot each body fills, from `0` to `1` (default `0.6`). A slot is the smallest gap between two `x` values. `wickWidth` is the wick's thickness in px.

```angular-html
<ui-candlestick-chart [data]="prices" [bodyWidthRatio]="0.8" [wickWidth]="2" />
```

### Axes and range

`xAxisLabel` and `yAxisLabel` add axis titles. Horizontal gridlines are on by default: `showGrid` turns them off, and `showXGrid` adds vertical ones.

```angular-html
<ui-candlestick-chart
  [data]="prices"
  xAxisLabel="Session"
  yAxisLabel="Price ($)"
  [yMin]="90"
/>
```

- `xMin`, `xMax`, `yMin` and `yMax` fix a bound instead of fitting the data, for example to compare two charts on one scale.
- `xTickFormat` and `yTickFormat` turn tick values into labels, for example a session index into a date.
- `tickCount` sets roughly how many ticks each axis gets. The axis picks round values near it.

### Padding

`padding` insets the plot, each side as a fraction (`0` to `1`) of its size.

```angular-html
<ui-candlestick-chart [data]="prices" [padding]="{ top: 0.05, bottom: 0.05 }" />
```

### Size

The chart fills its container's width and is 200px tall. Set `height` for another height and `width` for a fixed width, both in px. Use `height` rather than a height class, because the preset always sets a height.

```angular-html
<ui-candlestick-chart [data]="prices" [height]="260" />
```

## Interaction

### Taps

`candleTap` emits the tapped candle's `{ x, open, high, low, close }` item. A tap on empty space emits nothing. Set `tooltip` to `false` to turn the tooltip off.

```angular-html
<ui-candlestick-chart [data]="prices" (candleTap)="selected.set($event)" />
```

`candleTap` fires inside the touch, so wrap router navigation in `setTimeout` (see [the `setTimeout` rule](/guide/concepts/threads#the-settimeout-rule)).

### Pan and zoom

Set `zoomable` to let users drag to pan, with **+**, **−** and **1:1** buttons. Zooming in on the x axis spreads the candles apart, which suits a long price history.

```angular-html
<ui-candlestick-chart [data]="prices" [zoomable]="true" zoomAxes="x" />
```

To zoom from your own controls, set `showZoomControls` to `false` and call `zoomIn()`, `zoomOut()` or `resetZoom()` on the component. See [Pan and zoom](/dolan/chart#pan-and-zoom) for how it behaves.

## API

### UiCandlestickChart

| Input              | Type                            | Default                    | Description                                            |
| ------------------ | ------------------------------- | -------------------------- | ------------------------------------------------------ |
| `data`             | `readonly CandlestickDatum[]`   | Required                   | Candles, each `{ x, open, high, low, close }`.         |
| `upColor`          | `string`                        | `'rgba(34, 197, 94, 1)'`   | Color of a candle that closed at or above its open.    |
| `downColor`        | `string`                        | `'rgba(239, 68, 68, 1)'`   | Color of a candle that closed below its open.          |
| `wickWidth`        | `number`                        | `1`                        | Wick thickness in px.                                  |
| `bodyWidthRatio`   | `number`                        | `0.6`                      | Body width as a fraction of its slot, `0`–`1`.         |
| `width`            | `number`                        | _fills container_          | Fixed width in px.                                     |
| `height`           | `number`                        | `200`                      | Height in px.                                          |
| `tickCount`        | `number`                        | `5`                        | Target number of ticks per axis.                       |
| `showGrid`         | `boolean`                       | `true`                     | Horizontal gridlines at the y ticks.                   |
| `showXGrid`        | `boolean`                       | `false`                    | Vertical gridlines at the x ticks.                     |
| `xAxisLabel`       | `string`                        | `''`                       | X-axis title.                                          |
| `yAxisLabel`       | `string`                        | `''`                       | Y-axis title.                                          |
| `padding`          | `ChartPadding`                  | `{}`                       | Inner inset, each side a `0`–`1` fraction of the plot. |
| `xMin`             | `number`                        | _fits the data_            | Fixed x-axis lower bound.                              |
| `xMax`             | `number`                        | _fits the data_            | Fixed x-axis upper bound.                              |
| `yMin`             | `number`                        | _fits the data_            | Fixed y-axis lower bound.                              |
| `yMax`             | `number`                        | _fits the data_            | Fixed y-axis upper bound.                              |
| `xTickFormat`      | `(value: number) => string`     | _automatic_                | Formats x-axis tick labels.                            |
| `yTickFormat`      | `(value: number) => string`     | _automatic_                | Formats y-axis tick labels.                            |
| `tooltip`          | `boolean`                       | `true`                     | Show a tooltip for the touched candle. A tap pins it.  |
| `label`            | `string`                        | `'Chart'`                  | What a screen reader announces for the chart.          |
| `colorScheme`      | `'light' \| 'dark' \| 'system'` | _from `provideChartTheme`_ | Which color table the marks use.                       |
| `zoomable`         | `boolean`                       | `false`                    | Drag to pan, with zoom buttons.                        |
| `zoomAxes`         | `'x' \| 'y' \| 'xy'`            | `'xy'`                     | Which axes pan and zoom.                               |
| `showZoomControls` | `boolean`                       | `true`                     | Show the +/−/1:1 buttons when zoomable.                |
| `minZoom`          | `number`                        | `1`                        | Smallest zoom. `1` shows all the data.                 |
| `maxZoom`          | `number`                        | `8`                        | Largest zoom.                                          |
| `zoomStep`         | `number`                        | `1.4`                      | Zoom factor per button press or method call.           |
| `class`            | `string`                        | `''`                       | Extra Tailwind classes for the chart's root view.      |

| Output      | Type               | Description                 |
| ----------- | ------------------ | --------------------------- |
| `candleTap` | `CandlestickDatum` | The candle a tap landed on. |

| Method        | Description               |
| ------------- | ------------------------- |
| `zoomIn()`    | Zooms in by `zoomStep`.   |
| `zoomOut()`   | Zooms out by `zoomStep`.  |
| `resetZoom()` | Shows all the data again. |

`CandlestickDatum` is `{ x: number; open: number; high: number; low: number; close: number }`, exported from `../components/ui/candlestick-chart`. `ChartPadding` is `{ top?, right?, bottom?, left? }`, each a fraction (`0`–`1`) of the plot's size, with omitted sides `0`. It's exported from `../components/ui/chart`.

### candlestickChartDefinition

```typescript
function candlestickChartDefinition(
  options: CandlestickChartOptions,
): ChartDefinition;
```

Returns the [TanStack Charts](https://tanstack.com/charts) definition `<ui-candlestick-chart>` renders: a `link` mark for the wicks, a `rect` mark for the bodies, and a tooltip that lists all four prices. The options are the inputs that shape the chart, with the same defaults: `data`, `upColor`, `downColor`, `wickWidth`, `bodyWidthRatio`, `tickCount`, `showGrid`, `showXGrid`, `xAxisLabel`, `yAxisLabel`, `padding`, `xMin`, `xMax`, `yMin`, `yMax`, `xTickFormat`, `yTickFormat` and `tooltip`. Size, label, color scheme and zoom are inputs of `<ui-chart>` instead.

Start from it to add marks of your own, such as a price level or a moving average, and render the result with [`<ui-chart>`](/dolan/chart). Added marks get a plain x and y tooltip.

```typescript
import { defineChart, ruleY } from '@tanstack/charts/universal';
import { candlestickChartDefinition } from '../components/ui/candlestick-chart';

const base = candlestickChartDefinition({ data: prices });

protected readonly withPreviousClose = defineChart({
  ...base,
  marks: [
    ...base.marks,
    ruleY([104], { stroke: 'var(--muted-foreground)', strokeDasharray: '4 4' }),
  ],
});
```
