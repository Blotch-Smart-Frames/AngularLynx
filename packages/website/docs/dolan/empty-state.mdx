# Empty State

Fill an empty screen or list with a centered message, an optional icon, and an action that helps the user get started.

<Go example="ui-empty-state" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add empty-state
```

```typescript
import { UiEmptyState } from '../components/ui/empty-state';
```

This also adds [Icon](/dolan/icon), which draws the optional icon.

## Usage

```typescript
import { Component } from '@angular/core';
import { UiEmptyState } from '../components/ui/empty-state';

@Component({
  selector: 'app-no-results',
  imports: [UiEmptyState],
  template: `
    <ui-empty-state
      icon="search"
      title="No results found"
      description="Try adjusting your search or filters."
    />
  `,
})
export class NoResults {}
```

- `title` is required. `icon` and `description` are optional.
- `icon` takes any name from the [Icon](/dolan/icon) set, such as `'search'`, `'inbox'` or `'plus'`. It's drawn at the `lg` size.

### With an action

Put a button or other content inside. It renders below the description.

```angular-html
<ui-empty-state
  icon="inbox"
  title="No messages"
  description="Messages from your team show up here."
>
  <ui-button (pressed)="compose()">New message</ui-button>
</ui-empty-state>
```

Import [`UiButton`](/dolan/button) in your component for this.

## API

### UiEmptyState

| Input         | Type                    | Default     | Description                               |
| ------------- | ----------------------- | ----------- | ----------------------------------------- |
| `title`       | `string`                | Required    | Heading text.                             |
| `description` | `string`                | `''`        | Supporting text below the title.          |
| `icon`        | `IconName \| undefined` | `undefined` | Icon above the title.                     |
| `class`       | `string`                | `''`        | Extra Tailwind classes for the container. |

No outputs.
