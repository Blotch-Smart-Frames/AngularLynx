# Icon

195 vector icons from the [Lucide](https://lucide.dev) set, drawn with Lynx's `<svg>` element. It draws your own SVG too, such as a sign-in provider's mark.

## Installation

```bash
npx @blotch/dolan add icon
```

```typescript
import { UiIcon } from '../components/ui/icon';
```

## Usage

```typescript title="src/app/app.ts"
import { Component } from '@angular/core';
import { UiIcon } from '../components/ui/icon';

@Component({
  selector: 'app-root',
  imports: [UiIcon],
  template: `<ui-icon name="heart" size="lg" color="#ef4444" />`,
})
export class App {}
```

### Colors

Without `color`, an icon draws in your theme's foreground, like the text next to it. Pass `color` a theme token or a literal color:

```angular-html
<ui-icon name="trash" color="var(--destructive)" />
<ui-icon name="heart" color="#ef4444" />
```

- **Theme tokens are looked up in TypeScript.** Lynx's `<svg>` element can't read CSS, so `icon-theme.ts`, copied next to the icon, keeps the theme's colors. If you change a color in `default.css` or `dark.css`, pass the new value to `provideIconTheme()` too (see below). Text color classes such as `text-primary` have no effect on an icon.
- **Some containers color the icons inside them.** A destructive [nav drawer item](/dolan/nav-drawer) draws its icons in `--destructive`. The icon's own `color` still wins.

### Dark mode

Icons draw with the light theme's colors until you say otherwise, so they stay visible in an app without dark mode. If your app [switches the `.dark` class](/guide/dark-mode) with the phone's appearance, tell the icons to follow it too:

```typescript title="src/app/app.config.ts"
import { provideIconTheme } from '../components/ui/icon/icon-theme';

export const appConfig: ApplicationConfig = {
  providers: [
    // ...
    provideIconTheme({ colorScheme: 'system' }),
  ],
};
```

- **`'system'`** follows [`LynxTheme`](/api/angular-lynx/theme), the phone's appearance.
- **A function** such as `() => (settings.dark() ? 'dark' : 'light')` follows a theme setting of your own.
- **`light` and `dark`** take token values to override, if you changed your theme's colors.

The same setting colors [Spinner](/dolan/spinner), [Pagination](/dolan/pagination)'s arrows and a loading [Button](/dolan/button)'s spinner, and picks [Glass](/dolan/glass)'s light or dark material. Charts have their own, [`provideChartTheme()`](/dolan/chart).

### Your own SVG

For a mark the set doesn't have, such as a sign-in provider's, pass its markup to `svg` instead of `name`:

```typescript title="src/app/sign-in.ts"
import { Component } from '@angular/core';
import { UiButton } from '../components/ui/button';
import { UiIcon } from '../components/ui/icon';

@Component({
  selector: 'app-sign-in',
  imports: [UiButton, UiIcon],
  template: `
    <ui-button variant="outline">
      <ui-icon [svg]="githubMark" />
      Continue with GitHub
    </ui-button>
  `,
})
export class SignIn {
  // GitHub's mark (its path shortened here), filled with currentColor.
  readonly githubMark = `<svg viewBox="0 0 16 16"><path fill="currentColor" d="…"/></svg>`;
}
```

- **`currentColor` takes the icon's color,** as the set's icons do: `color`, a button's label color, or the theme's foreground. A one-color mark written in `currentColor` follows your theme, and dark mode as set above.
- **Colors written out stay,** so a multi-color mark, such as Google's, keeps them.
- **`xmlns` is optional.** The icon adds it to the root `<svg>`: without it, the web preview draws nothing.
- **Draw lines with `<path>`.** The [`<svg>` element](/api/elements/svg) has the same limits here: no `<line>` on iOS and Android, and no CSS.
- **Give an icon `name` or `svg`, not both.** With neither or both, it throws an error.

The example at the top of this page draws Google's and GitHub's marks, and [Button](/dolan/button)'s example puts them in sign-in buttons.

### Sizes

```angular-html
<ui-icon name="heart" size="xs" />
<ui-icon name="heart" size="sm" />
<ui-icon name="heart" size="md" />
<ui-icon name="heart" size="lg" />
```

The sizes are 16, 20, 24 (the default) and 32 pixels square.

### Type-safe names

`IconName` is the union of every icon name. `ICONS` maps each name to its SVG markup, so `Object.keys(ICONS)` lists them all.

```typescript
import { signal } from '@angular/core';
import { type IconName } from '../components/ui/icon';

const current = signal<IconName>('check');
```

### Spacing

`class` takes Tailwind classes for the icon, such as `class="mr-2"`.

## API

### UiIcon

| Input   | Type                           | Default     | Description                                                                                                                                                 |
| ------- | ------------------------------ | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`  | `IconName \| undefined`        | `undefined` | An icon from the set. Give this or `svg`.                                                                                                                   |
| `svg`   | `string \| undefined`          | `undefined` | SVG markup to draw instead, such as a sign-in provider's mark. Give this or `name`.                                                                         |
| `size`  | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'md'`      | 16, 20, 24 or 32 pixels square.                                                                                                                             |
| `color` | `string \| undefined`          | `undefined` | The color of the set's strokes and of `currentColor` in `svg`: a theme token such as `var(--primary)`, or a literal color. The theme's foreground if unset. |
| `class` | `string`                       | `''`        | Extra Tailwind classes for the icon.                                                                                                                        |

No outputs.
