# Icon

195 vector icons from the [Lucide](https://lucide.dev) set, drawn with Lynx's `<svg>` element.

<Go example="ui-icon" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add icon
```

```typescript
import { UiIcon } from '../components/ui/icon';
```

## Usage

```typescript title="src/app/app.ts"
import { Component } from '@angular/core';
import { UiIcon } from '../components/ui/icon';

@Component({
  selector: 'app-root',
  imports: [UiIcon],
  template: `<ui-icon name="heart" size="lg" color="#ef4444" />`,
})
export class App {}
```

### Colors

Pass `color` a literal color, such as `#71717a` or `rgba(9, 9, 11, 1)`.

- The icon's SVG is drawn on its own, so it can't read CSS. `var(--primary)` and text color classes have no effect.
- Without `color`, the icon keeps its SVG's `currentColor`, which doesn't follow your text color.
- If you use dark mode, pick the color from your theme signal, for example `[color]="theme.isDarkMode() ? '#fafafa' : '#09090b'"`.

### Sizes

```angular-html
<ui-icon name="heart" size="xs" />
<ui-icon name="heart" size="sm" />
<ui-icon name="heart" size="md" />
<ui-icon name="heart" size="lg" />
```

The sizes are 16, 20, 24 (the default) and 32 pixels square.

### Type-safe names

`IconName` is the union of every icon name. `ICONS` maps each name to its SVG markup, so `Object.keys(ICONS)` lists them all.

```typescript
import { signal } from '@angular/core';
import { type IconName } from '../components/ui/icon';

const current = signal<IconName>('check');
```

### Spacing

`UiIcon` has no `class` input. A `class` you write on `<ui-icon>` lands on its outer element, which is enough for margins such as `class="mr-2"`.

## API

### UiIcon

| Input   | Type                           | Default     | Description                                            |
| ------- | ------------------------------ | ----------- | ------------------------------------------------------ |
| `name`  | `IconName`                     | Required    | The icon to draw.                                      |
| `size`  | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'md'`      | 16, 20, 24 or 32 pixels square.                        |
| `color` | `string \| undefined`          | `undefined` | Stroke color. Must be a literal color, not `var(--x)`. |

No outputs.
