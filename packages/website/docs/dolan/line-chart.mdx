# Line Chart

Plot one series of points as a line, with a dot at each point. It's a preset of [`<ui-chart>`](/dolan/chart): it builds a [TanStack Charts](https://tanstack.com/charts) definition from its inputs, so it has the same touch tooltip, screen reader support, pan and zoom, and dark mode.

<Go example="ui-line-chart" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add line-chart
```

:::tip
The line chart depends on [`chart`](/dolan/chart), which is added automatically, along with the npm packages it imports: `@tanstack/charts` and `d3-shape`.
:::

```typescript
import { UiLineChart } from '@/components/ui/line-chart';
```

## Usage

Pass an array of `{ x, y }` points, both numbers. The chart fits rounded axis ranges to the data.

```angular-html
<ui-line-chart [data]="revenue" label="Monthly revenue" />
```

```typescript
revenue = [
  { x: 1, y: 12 },
  { x: 2, y: 19 },
  { x: 3, y: 15 },
  { x: 4, y: 25 },
];
```

Touch the chart to see a point's values in a tooltip, and tap to pin it. Set `label` so a screen reader can say what the chart shows.

### Color and thickness

`color` sets the line and the dots. A theme color such as `var(--chart-2)` switches with [dark mode](/dolan/chart#dark-mode); a fixed color such as `rgba(59, 130, 246, 1)` stays the same.

```angular-html
<ui-line-chart
  [data]="downloads"
  color="var(--chart-2)"
  [strokeWidth]="3"
  [dotRadius]="4"
/>
```

Set `showDots` to `false` for a line without dots.

### Smooth curve

Set `smooth` to draw a curve through the points instead of straight segments. The dots stay on the data.

```angular-html
<ui-line-chart [data]="revenue" [smooth]="true" />
```

The curve is monotone (d3's `curveMonotoneX`): it never overshoots the data, so the line stays within the values it passes through.

### Label the axes

`xAxisLabel` and `yAxisLabel` add axis titles. Horizontal gridlines are on by default; `showGrid` turns them off and `showXGrid` adds vertical ones.

```angular-html
<ui-line-chart
  [data]="revenue"
  xAxisLabel="Month"
  yAxisLabel="Revenue ($k)"
  [showXGrid]="true"
/>
```

### Format the ticks

`xTickFormat` and `yTickFormat` turn tick values into labels. `tickCount` sets roughly how many ticks each axis gets; the axis picks round values near it.

```angular-html
<ui-line-chart [data]="revenue" [xTickFormat]="monthName" />
```

```typescript
readonly months = ['Jan', 'Feb', 'Mar', 'Apr'];
readonly monthName = (value: number) => this.months[value - 1] ?? '';
```

### Fix the axis range

By default the axes fit the data. Pass `yMin` and `yMax` (or `xMin` and `xMax`) to fix a bound, most often `yMin` of `0` to start the axis at zero.

```angular-html
<ui-line-chart [data]="revenue" [yMin]="0" />
```

### Pad the plot edges

`padding` insets the plot, each side as a fraction (`0` to `1`) of its size. Use it to keep the first and last dots off the frame.

```angular-html
<ui-line-chart [data]="revenue" [padding]="{ left: 0.05, right: 0.05 }" />
```

### Size

The chart fills its container's width and is 200px tall. Set `height` for a different height, and `width` for a fixed width, both in px.

```angular-html
<ui-line-chart [data]="revenue" [height]="160" />
```

### Handle taps

`pointTap` emits the tapped `{ x, y }` point. Set `tooltip` to `false` to turn the tooltip off.

```angular-html
<ui-line-chart [data]="revenue" (pointTap)="onPointTap($event)" />
```

### Pan and zoom

Set `zoomable` to let users drag to pan, with **+**, **−** and **1:1** buttons.

```angular-html
<ui-line-chart [data]="revenue" [zoomable]="true" zoomAxes="x" />
```

See [Pan and zoom](/dolan/chart#pan-and-zoom) on the Chart page for how it behaves. To zoom from your own controls, call `zoomIn()`, `zoomOut()` or `resetZoom()` on the component.

## Several series, overlays and other marks

The preset draws one series. For several lines, a target line, or any other mark, build a definition and render it with [`<ui-chart>`](/dolan/chart#several-series). You can start from this preset's definition to keep its axes and styling:

```typescript
import { defineChart, ruleY } from '@tanstack/charts/universal';
import { lineChartDefinition } from '@/components/ui/line-chart';

const base = lineChartDefinition({ data: revenue, smooth: true, yMin: 0 });

const withTarget = defineChart({
  ...base,
  marks: [...base.marks, ruleY([20], { stroke: 'var(--muted-foreground)' })],
});
```

```angular-html
<ui-chart [definition]="withTarget" label="Revenue against target" />
```

## API

### UiLineChart

| Input              | Type                            | Default                    | Description                                                   |
| ------------------ | ------------------------------- | -------------------------- | ------------------------------------------------------------- |
| `data`             | `XYDatum[]`                     | _required_                 | Points to plot, each `{ x, y }`                               |
| `color`            | `string`                        | `'var(--primary)'`         | Line and dot color (any CSS color)                            |
| `strokeWidth`      | `number`                        | `2`                        | Line thickness in px                                          |
| `dotRadius`        | `number`                        | `3`                        | Dot radius in px                                              |
| `showDots`         | `boolean`                       | `true`                     | Draw a dot at each point                                      |
| `smooth`           | `boolean`                       | `false`                    | Draw a monotone curve instead of straight segments            |
| `width`            | `number`                        | _fills container_          | Fixed width in px                                             |
| `height`           | `number`                        | `200`                      | Height in px                                                  |
| `tickCount`        | `number`                        | `5`                        | Target number of ticks per axis                               |
| `showGrid`         | `boolean`                       | `true`                     | Horizontal gridlines at the y ticks                           |
| `showXGrid`        | `boolean`                       | `false`                    | Vertical gridlines at the x ticks                             |
| `xAxisLabel`       | `string`                        | `''`                       | X-axis title                                                  |
| `yAxisLabel`       | `string`                        | `''`                       | Y-axis title                                                  |
| `padding`          | `ChartPadding`                  | `{}`                       | Inner inset, each side a `0`–`1` fraction of the plot         |
| `xMin`             | `number`                        | _auto_                     | Fixed x-axis lower bound                                      |
| `xMax`             | `number`                        | _auto_                     | Fixed x-axis upper bound                                      |
| `yMin`             | `number`                        | _auto_                     | Fixed y-axis lower bound                                      |
| `yMax`             | `number`                        | _auto_                     | Fixed y-axis upper bound                                      |
| `xTickFormat`      | `(value: number) => string`     | _auto_                     | Formats x-axis tick labels                                    |
| `yTickFormat`      | `(value: number) => string`     | _auto_                     | Formats y-axis tick labels                                    |
| `tooltip`          | `boolean`                       | `true`                     | Show a tooltip for the touched point; a tap pins it           |
| `label`            | `string`                        | `'Chart'`                  | What a screen reader announces for the chart                  |
| `colorScheme`      | `'light' \| 'dark' \| 'system'` | _from `provideChartTheme`_ | Light or dark colors; see [Dark mode](/dolan/chart#dark-mode) |
| `zoomable`         | `boolean`                       | `false`                    | Drag to pan, with zoom buttons                                |
| `zoomAxes`         | `'x' \| 'y' \| 'xy'`            | `'xy'`                     | Which axes pan and zoom                                       |
| `showZoomControls` | `boolean`                       | `true`                     | Show the +/−/1:1 buttons when zoomable                        |
| `minZoom`          | `number`                        | `1`                        | Smallest zoom; `1` shows all the data                         |
| `maxZoom`          | `number`                        | `8`                        | Largest zoom                                                  |
| `zoomStep`         | `number`                        | `1.4`                      | Zoom factor per button press                                  |
| `class`            | `string`                        | `''`                       | Additional CSS classes                                        |

| Output     | Type      | Description                     |
| ---------- | --------- | ------------------------------- |
| `pointTap` | `XYDatum` | Emits the point that was tapped |

| Method        | Description              |
| ------------- | ------------------------ |
| `zoomIn()`    | Zooms in by `zoomStep`   |
| `zoomOut()`   | Zooms out by `zoomStep`  |
| `resetZoom()` | Shows all the data again |

`XYDatum` is `{ x: number; y: number }` and `ChartPadding` is `{ top?, right?, bottom?, left? }`, each a fraction (`0`–`1`) of the plot's size, with omitted sides `0`. Both are exported from `@/components/ui/chart`.

### lineChartDefinition

`lineChartDefinition(options: LineChartOptions)` returns the TanStack definition `<ui-line-chart>` renders. The options are the inputs that shape the chart, with the same defaults: `data`, `color`, `strokeWidth`, `dotRadius`, `showDots`, `smooth`, `tickCount`, `showGrid`, `showXGrid`, `xAxisLabel`, `yAxisLabel`, `padding`, `xMin`, `xMax`, `yMin`, `yMax`, `xTickFormat`, `yTickFormat` and `tooltip`. Size, label and zoom are inputs of `<ui-chart>` instead.
