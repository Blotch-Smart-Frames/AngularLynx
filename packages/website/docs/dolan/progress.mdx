# Progress

Show how far a task has got with a horizontal bar that fills as the value grows.

<Go example="ui-progress" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add progress
```

```typescript
import { UiProgress } from '../components/ui/progress';
```

## Usage

```typescript
import { Component, signal } from '@angular/core';
import { UiProgress } from '../components/ui/progress';

@Component({
  selector: 'app-upload',
  imports: [UiProgress],
  template: `<ui-progress [value]="uploaded()" />`,
})
export class Upload {
  protected readonly uploaded = signal(30);
}
```

- `value` runs from `0` to `max`, which is `100` by default. Values outside that range are clamped.
- When `value` changes, the fill animates to its new width. The first render doesn't animate.
- The bar fills its parent's width. Set a width class to change that.

### Custom max

```angular-html
<ui-progress [value]="150" [max]="200" />
```

### Indeterminate

Set `indeterminate` when you can't tell how far along the task is. A short fill slides across the track over and over, and `value` is ignored.

```angular-html
<ui-progress indeterminate />
```

## API

### UiProgress

| Input           | Type      | Default | Description                                              |
| --------------- | --------- | ------- | -------------------------------------------------------- |
| `value`         | `number`  | `0`     | Current value, from `0` to `max`.                        |
| `max`           | `number`  | `100`   | The value of a full bar. `0` or less shows an empty bar. |
| `indeterminate` | `boolean` | `false` | Loop a sliding fill instead of showing `value`.          |
| `class`         | `string`  | `''`    | Extra Tailwind classes for the track.                    |

No outputs.
