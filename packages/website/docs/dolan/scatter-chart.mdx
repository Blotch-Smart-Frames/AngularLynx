# Scatter Chart

Plot `{ x, y }` points as dots — drawn entirely from Lynx views, no SVG or canvas. Each point is one circular view. Built on the same **cartesian chart base** as the [Line Chart](/dolan/line-chart), [Area Chart](/dolan/area-chart), [Bar Chart](/dolan/bar-chart), and [Candlestick Chart](/dolan/candlestick-chart).

<Go example="ui-scatter-chart" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add scatter-chart
```

:::tip
The base **`cartesian-chart`** (axes, gridlines, scales) is a dependency and installs automatically.
:::

```typescript
import { UiScatterChart } from '@/components/ui/scatter-chart';
```

## Usage

Pass an array of `{ x, y }` points — the same shape the line and area charts use. The wrapper picks rounded axis ranges for you and insets the edges so dots at the extremes aren't clipped.

```angular-html
<ui-scatter-chart [data]="measurements" [width]="280" [height]="200" />
```

```typescript
measurements = [
  { x: 1, y: 3 },
  { x: 2, y: 4 },
  { x: 4, y: 6 },
  { x: 8, y: 10 },
];
```

`x` is a plain number, not a `Date` — see the note below.

### Color the dots

`color` fills every dot (default `var(--primary)`). Pass `colors` to tint each dot — the palette cycles if it's shorter than the data, so index the array to group membership for a categorical scatter.

```angular-html
<ui-scatter-chart [data]="clusters" [colors]="clusterColors" />
```

```typescript
// First five points blue, the rest orange.
clusterColors = [
  'rgba(59, 130, 246, 1)',
  'rgba(59, 130, 246, 1)',
  'rgba(59, 130, 246, 1)',
  'rgba(249, 115, 22, 1)',
  'rgba(249, 115, 22, 1)',
  'rgba(249, 115, 22, 1)',
];
```

### Size the dots (bubble chart)

`radius` sets a uniform dot radius in px. Pass `sizes` to give each dot its own radius — a bubble chart, encoding a third value as the dot's size.

```angular-html
<ui-scatter-chart [data]="measurements" [sizes]="bubbleSizes" />
```

```typescript
bubbleSizes = [4, 6, 5, 9, 7, 12, 8, 14]; // px radius, indexed 1:1 with data
```

### Label the axes

Set `xAxisLabel` / `yAxisLabel` for axis titles. `showXGrid` adds vertical gridlines.

```angular-html
<ui-scatter-chart
  [data]="measurements"
  xAxisLabel="Dose"
  yAxisLabel="Response"
  [showXGrid]="true"
/>
```

### Fix the axis range

Pass `xMin` / `xMax` / `yMin` / `yMax` to pin an axis bound instead of fitting the data — useful to compare two charts on one scale.

```angular-html
<ui-scatter-chart [data]="measurements" [yMin]="0" [yMax]="14" />
```

### Handle taps

`pointTap` emits the tapped `{ x, y }` point.

```angular-html
<ui-scatter-chart [data]="measurements" (pointTap)="onPointTap($event)" />
```

### Add a regression line

For an overlay, drop to the base `<ui-cartesian-chart>` and layer a [`<ui-line-series>`](/dolan/line-chart#uilineseries) under a `<ui-scatter-series>`. Both read the shared axes, so they line up. (The line renders first so the dots paint on top.)

```angular-html
<ui-cartesian-chart
  [xDomain]="[0, 11]"
  [yDomain]="[0, 14]"
  [xTicks]="[0, 2, 4, 6, 8, 10]"
  [yTicks]="[0, 4, 8, 12]"
  [width]="280"
  [height]="200"
>
  <ui-line-series [data]="regression" [showDots]="false" />
  <ui-scatter-series [data]="measurements" />
</ui-cartesian-chart>
```

:::info Why numbers, not dates
Lynx has no `Intl`, so the whole chart system keeps `x` **numeric** rather than a `Date` — format tick labels with `xTickFormat` if you need them. Both axes fit the data extremes (there's no baseline), and the wrapper adds a small inset so edge dots aren't clipped.
:::

### Pan and zoom

Set `zoomable` for pinch-to-zoom and drag-to-pan, with on-screen `+` / `−` / `1:1` controls. The axes and gridlines update live as you zoom. Off by default.

```angular-html
<ui-scatter-chart [data]="measurements" [zoomable]="true" />
```

See [Pan and zoom](/dolan/line-chart#pan-and-zoom) for the shared options (`zoomAxes`, `minZoom`, `maxZoom`) and the `zoomIn()` / `zoomOut()` / `resetZoom()` methods.

## API

### UiScatterChart

The single-series convenience wrapper. Auto-computes both axes from `data` and insets the edges.

| Input              | Type                        | Default            | Description                                      |
| ------------------ | --------------------------- | ------------------ | ------------------------------------------------ |
| `data`             | `ChartPoint[]`              | _required_         | Points, each `{ x, y }`                          |
| `color`            | `string`                    | `'var(--primary)'` | Fill for every dot (overridden by `colors`)      |
| `colors`           | `string[]`                  | `[]`               | Per-dot fills; cycles when shorter than the data |
| `radius`           | `number`                    | `4`                | Uniform dot radius in px (overridden by `sizes`) |
| `sizes`            | `number[]`                  | `[]`               | Per-dot radii in px (a bubble chart)             |
| `width`            | `number`                    | `320`              | Chart width in px                                |
| `height`           | `number`                    | `200`              | Chart height in px                               |
| `tickCount`        | `number`                    | `5`                | Target number of axis ticks                      |
| `showXGrid`        | `boolean`                   | `false`            | Draw vertical gridlines at x ticks               |
| `xAxisLabel`       | `string`                    | `''`               | X-axis title                                     |
| `yAxisLabel`       | `string`                    | `''`               | Y-axis title                                     |
| `padding`          | `ChartPadding`              | _auto_             | Inner inset (merged over auto edge-inset)        |
| `xMin`             | `number`                    | _auto_             | Force x-axis lower bound                         |
| `xMax`             | `number`                    | _auto_             | Force x-axis upper bound                         |
| `yMin`             | `number`                    | _auto_             | Force y-axis lower bound                         |
| `yMax`             | `number`                    | _auto_             | Force y-axis upper bound                         |
| `xTickFormat`      | `(value: number) => string` | rounds to 2 dp     | Formats x-axis labels                            |
| `yTickFormat`      | `(value: number) => string` | rounds to 2 dp     | Formats y-axis labels                            |
| `zoomable`         | `boolean`                   | `false`            | Enable pinch/drag zoom + controls                |
| `zoomAxes`         | `'x' \| 'y' \| 'xy'`        | `'xy'`             | Which axes zoom/pan affect                       |
| `showZoomControls` | `boolean`                   | `true`             | Show the +/−/1:1 controls when zoomable          |
| `minZoom`          | `number`                    | `1`                | Lower zoom bound (1 = fit all data)              |
| `maxZoom`          | `number`                    | `8`                | Upper zoom bound                                 |
| `zoomStep`         | `number`                    | `1.4`              | Zoom factor per +/− control press                |
| `class`            | `string`                    | `''`               | Additional CSS classes                           |

| Output     | Type         | Description                          |
| ---------- | ------------ | ------------------------------------ |
| `pointTap` | `ChartPoint` | Emits the point when a dot is tapped |

### UiScatterSeries

One scatter series inside a `<ui-cartesian-chart>`. Reads the shared axes from the chart.

| Input    | Type           | Default            | Description                                      |
| -------- | -------------- | ------------------ | ------------------------------------------------ |
| `data`   | `ChartPoint[]` | _required_         | Points, each `{ x, y }`                          |
| `color`  | `string`       | `'var(--primary)'` | Fill for every dot (overridden by `colors`)      |
| `colors` | `string[]`     | `[]`               | Per-dot fills; cycles when shorter than the data |
| `radius` | `number`       | `4`                | Uniform dot radius in px (overridden by `sizes`) |
| `sizes`  | `number[]`     | `[]`               | Per-dot radii in px (a bubble chart)             |
| `class`  | `string`       | `''`               | Additional CSS classes                           |

| Output     | Type         | Description                          |
| ---------- | ------------ | ------------------------------------ |
| `pointTap` | `ChartPoint` | Emits the point when a dot is tapped |

The x/y axes come from the surrounding [`UiCartesianChart`](/dolan/line-chart#uicartesianchart) — see the Line Chart page for its inputs.
