# Select

A field that opens a bottom sheet of options and shows the one the user picks. Long lists get a search field.

<Go example="ui-select" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add select
```

```typescript
import { UiSelect, UiSelectItem } from '../components/ui/select';
```

:::tip
This also adds [Bottom Sheet](/dolan/bottom-sheet), which holds the options, [Search Field](/dolan/search-field), for a searchable select, and the [Glass](/dolan/glass) and [Icon](/dolan/icon) its platform look draws with.
:::

## Usage

```typescript title="src/app/app.ts"
import { Component, signal } from '@angular/core';
import { UiSelect, UiSelectItem } from '../components/ui/select';

@Component({
  selector: 'app-root',
  imports: [UiSelect, UiSelectItem],
  template: `
    <ui-select placeholder="Pick a country" [(value)]="country">
      <ui-select-item value="us" label="United States" />
      <ui-select-item value="uk" label="United Kingdom" />
      <ui-select-item value="jp" label="Japan" />
    </ui-select>
  `,
})
export class App {
  protected readonly country = signal('');
}
```

- Tapping the field opens the sheet. Tapping an item selects it and closes the sheet.
- Tapping the dimmed backdrop, or dragging the sheet's handle down, closes it without a change.
- The field shows the selected item's `label`, or `placeholder` when nothing is selected. The selected item has a check mark.
- The list scrolls once it's taller than 300 pixels. A [searchable](#search) select's list fills the sheet instead.

### With a label

```angular-html
<ui-select
  label="Country"
  placeholder="Choose your country"
  [(value)]="country"
>
  …
</ui-select>
```

`label` is shown above the field and names it for screen readers. A label of your own beside the field, such as a [Label](/dolan/label), isn't tied to it, so give the select an `accessibility-label` with the same text:

```angular-html
<view class="flex flex-col gap-2">
  <ui-label>Country</ui-label>
  <ui-select accessibility-label="Country" [(value)]="country">…</ui-select>
</view>
```

### Search

Add `searchable` for a long list, such as time zones or countries:

```angular-html
<ui-select label="Time zone" searchable [(value)]="timeZone">
  @for (zone of timeZones; track zone) {
    <ui-select-item [value]="zone" [label]="zone" />
  }
</ui-select>
```

- The sheet opens at full height, with a [Search Field](/dolan/search-field) at the top. The keyboard rises below it.
- Typing hides every item whose `label` doesn't contain the text. Case doesn't matter.
- `emptyText` shows when nothing matches. It defaults to `No results`.
- The text clears when the sheet closes, so it opens on the full list next time.
- Bind `[(query)]` to read or set the text.

### Results of your own

Set `[filter]="false"` to show your own results for the text, such as suggestions from a server:

```angular-html
<ui-select
  label="Address"
  searchable
  [filter]="false"
  [emptyText]="query() ? 'No addresses found' : 'Start typing an address'"
  [(query)]="query"
  [(value)]="address"
>
  @for (result of results(); track result.id) {
    <ui-select-item [value]="result.id" [label]="result.text" />
  }
</ui-select>
```

```typescript
protected readonly query = signal('');
protected readonly address = signal('');
// Fetches suggestions whenever the query changes.
protected readonly suggestions = httpResource<Suggestion[]>(() => {
  const query = this.query().trim();
  return query
    ? `https://api.example.com/addresses?q=${encodeURIComponent(query)}`
    : undefined;
});
protected readonly results = computed(() => this.suggestions.value() ?? []);
```

See [HTTP requests](/guide/http) for `httpResource` on Lynx.

The field shows the chosen item's `label`. Once the item is gone from the list, it shows the `value` itself. Keep the chosen result among the items to keep its label in the field.

### Icons

Put content in an item, such as an [Icon](/dolan/icon), and it goes before the label. Mark content `leading` on the select itself to show it in the field, before the text:

```angular-html
<ui-select label="Weather" [(value)]="weather">
  <ui-icon leading [name]="weather()" size="xs" />
  <ui-select-item value="sun" label="Sunny">
    <ui-icon name="sun" size="sm" />
  </ui-select-item>
  <ui-select-item value="cloud" label="Cloudy">
    <ui-icon name="cloud" size="sm" />
  </ui-select-item>
</ui-select>
```

### Platform look

`variant="glass"` opens the options in each platform's own sheet, the [Bottom Sheet's glass variant](/dolan/bottom-sheet#glass), and draws them as that platform's lists do:

```angular-html
<ui-select label="Time zone" searchable variant="glass" [(value)]="timeZone">
  …
</ui-select>
```

| Platform         | Sheet                          | Rows                                                                                                 |
| ---------------- | ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| iOS 26 and later | Liquid Glass                   | 44pt tall, 17pt text, the chosen one marked by a check in the tint                                   |
| iOS 15 to 25     | That iOS's opaque sheet        | The same                                                                                             |
| Android          | Material 3's bottom sheet      | 56dp one-line list items, 16sp text, the chosen one on the secondary container, its check in primary |
| Web preview      | Liquid Glass, drawn with WebGL | As on iOS 26                                                                                         |

The rows follow the design the sheet draws, so Android with [`provideGlass({ android: 'glass' })`](/dolan/glass) gets iOS's rows on glass. The search field follows the platform in every variant. Without `variant`, the select looks the same everywhere, with rows at least 44px tall.

### Accessibility

- The field is one button to VoiceOver and TalkBack, named by `label` (or `accessibility-label`), with the chosen item's label, or the placeholder, as its value: VoiceOver says "Country, Germany, button". Without either, the field's name is the text it shows.
- A disabled field is dimmed to VoiceOver as well.
- Each item is a button named by its `label`, and the chosen one is `selected`, as its check mark shows.
- Content in the field and the items, such as icons, isn't read. The label says what they mean.

So a spec finds them by role:

```typescript
fireEvent.tap(screen.getByRole('button', { name: 'Country' }));
fireEvent.tap(await screen.findByRole('button', { name: 'Germany' }));
expect(
  screen.getByRole('button', { name: 'Germany', selected: true }),
).toBeTruthy();
```

### Disabled

```angular-html
<ui-select value="admin" disabled>
  <ui-select-item value="admin" label="Administrator" />
  <ui-select-item value="viewer" label="Viewer" />
</ui-select>
```

A disabled select dims and doesn't open.

### Open from code

`UiSelect` has public `open()`, `close()` and `toggle()` methods. Get it with `viewChild(UiSelect)` and call them from a handler. `open()` and `toggle()` do nothing while disabled.

## API

### UiSelect

| Input                 | Type                   | Default        | Description                                                                                             |
| --------------------- | ---------------------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `value`               | `string`               | `''`           | The selected item's value. Supports `[(value)]`.                                                        |
| `label`               | `string`               | `''`           | Shown above the field, and read by screen readers as its name.                                          |
| `placeholder`         | `string`               | `'Select...'`  | Shown in the field while nothing is selected.                                                           |
| `accessibility-label` | `string`               | `''`           | The field's name for screen readers when it has no `label`.                                             |
| `disabled`            | `boolean`              | `false`        | Dims the field and stops it from opening.                                                               |
| `class`               | `string`               | `''`           | Extra Tailwind classes for the column that holds the label and the field.                               |
| `searchable`          | `boolean`              | `false`        | Shows a search field in the sheet, which opens at full height.                                          |
| `query`               | `string`               | `''`           | The search text. Supports `[(query)]`. Cleared when the sheet closes.                                   |
| `filter`              | `boolean`              | `true`         | Hides the items whose `label` doesn't contain `query`, ignoring case.                                   |
| `searchPlaceholder`   | `string`               | `'Search'`     | Shown in the search field while it's empty.                                                             |
| `emptyText`           | `string`               | `'No results'` | Shown in a searchable sheet while no item is.                                                           |
| `variant`             | `'default' \| 'glass'` | `'default'`    | `'glass'` opens the options in each platform's own sheet and rows. See [Platform look](#platform-look). |

| Output        | Type     | Description                                  |
| ------------- | -------- | -------------------------------------------- |
| `changed`     | `string` | Emits the value of the item the user tapped. |
| `valueChange` | `string` | Emits the new value, for `[(value)]`.        |
| `queryChange` | `string` | Emits the search text, for `[(query)]`.      |

| Content       | Description                                        |
| ------------- | -------------------------------------------------- |
| `[leading]`   | Shown in the field, before the text.               |
| Anything else | The items, `<ui-select-item>`, shown in the sheet. |

### UiSelectItem

| Input   | Type     | Default  | Description                                  |
| ------- | -------- | -------- | -------------------------------------------- |
| `value` | `string` | Required | The value this item selects.                 |
| `label` | `string` | Required | The text shown in the list and in the field. |
| `class` | `string` | `''`     | Extra Tailwind classes for the item's row.   |

No outputs. Content inside the item, such as an icon, goes before its label.
