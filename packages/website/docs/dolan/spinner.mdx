# Spinner

Show that something is loading with a rotating icon, when you can't tell how long it will take.

<Go example="ui-spinner" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add spinner
```

```typescript
import { UiSpinner } from '../components/ui/spinner';
```

## Usage

```typescript
import { Component } from '@angular/core';
import { UiSpinner } from '../components/ui/spinner';

@Component({
  selector: 'app-loading',
  imports: [UiSpinner],
  template: `<ui-spinner color="rgba(113, 113, 122, 1)" />`,
})
export class Loading {}
```

- The spinner turns once every 1.6 seconds, for as long as it's on screen.
- It's drawn with [Lynx](/guide/glossary#lynx)'s [`<svg>`](/api/elements/svg) element, which can't read your CSS. Pass `color` as a literal color, such as `#3b82f6` or `rgba(…)`. A theme variable such as `var(--primary)` won't work there.
- Without `color`, the icon keeps the SVG's `currentColor` stroke, which doesn't follow your theme. Set `color` whenever the spinner sits on a dark background or the app has dark mode.
- It has no `class` input. Wrap it in a `<view>` to position it.

### Sizes

```angular-html
<ui-spinner size="xs" />
<ui-spinner size="sm" />
<ui-spinner size="md" />
<ui-spinner size="lg" />
```

`xs` is 16px, `sm` 20px, `md` 24px and `lg` 32px.

### In a button

[Button](/dolan/button) shows a spinner in place of its label while `loading` is `true`, so you don't need to add one yourself.

## API

### UiSpinner

| Input   | Type                           | Default     | Description                                           |
| ------- | ------------------------------ | ----------- | ----------------------------------------------------- |
| `size`  | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'md'`      | Width and height: 16, 20, 24 or 32px.                 |
| `color` | `string \| undefined`          | `undefined` | Stroke color, as a literal color. Not a CSS variable. |

No outputs.
