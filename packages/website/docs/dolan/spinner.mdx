# Spinner

Show that something is loading with a rotating icon, when you can't tell how long it will take.

<Go example="ui-spinner" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add spinner
```

```typescript
import { UiSpinner } from '../components/ui/spinner';
```

## Usage

```typescript
import { Component } from '@angular/core';
import { UiSpinner } from '../components/ui/spinner';

@Component({
  selector: 'app-loading',
  imports: [UiSpinner],
  template: `<ui-spinner color="var(--muted-foreground)" />`,
})
export class Loading {}
```

- The spinner turns once every 1.6 seconds, for as long as it's on screen.
- Without `color`, it draws in your theme's foreground. `color` takes a theme token such as `var(--primary)` or a literal color such as `#3b82f6`.
- It's drawn with [Lynx](/guide/glossary#lynx)'s [`<svg>`](/api/elements/svg) element, which can't read your CSS, so theme tokens are looked up the way [Icon](/dolan/icon#colors) does it. For dark mode, see [Icon](/dolan/icon#dark-mode): the same `provideIconTheme()` setting colors the spinner.
- `class` takes Tailwind classes for the spinner, such as `class="ml-2"`.

### Sizes

```angular-html
<ui-spinner size="xs" />
<ui-spinner size="sm" />
<ui-spinner size="md" />
<ui-spinner size="lg" />
```

`xs` is 16px, `sm` 20px, `md` 24px and `lg` 32px.

### In a button

[Button](/dolan/button) shows a spinner in place of its label while `loading` is `true`, in the label's color, so you don't need to add one yourself.

## API

### UiSpinner

| Input   | Type                           | Default     | Description                                                                                                |
| ------- | ------------------------------ | ----------- | ---------------------------------------------------------------------------------------------------------- |
| `size`  | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'md'`      | Width and height: 16, 20, 24 or 32px.                                                                      |
| `color` | `string \| undefined`          | `undefined` | Stroke color: a theme token such as `var(--primary)`, or a literal color. The theme's foreground if unset. |
| `class` | `string`                       | `''`        | Extra Tailwind classes for the spinner.                                                                    |

No outputs.
