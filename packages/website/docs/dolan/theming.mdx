# Theming

Change your app's entire look by editing a handful of CSS variables. Dolan's theming system — inspired by [shadcn/ui](https://ui.shadcn.com/docs/theming) — uses **semantic color tokens** that all components reference. Swap the values and every button, card, and input updates automatically.

## Quick Overview

Define HSL color values on the `page` element (Lynx's root):

```css title="src/styles/default.css"
page {
  --primary: 240 5.9% 10%;
  --primary-foreground: 0 0% 98%;
}
```

Use them via Tailwind utilities:

```html
<view class="bg-primary text-primary-foreground">...</view>
```

Toggle dark mode with a `.dark` class:

```css title="src/styles/dark.css"
page.dark {
  --primary: 0 0% 98%;
  --primary-foreground: 240 5.9% 10%;
}
```

## Color Tokens

| Token                                    | Purpose                            | Used by                                    |
| ---------------------------------------- | ---------------------------------- | ------------------------------------------ |
| `background` / `foreground`              | Default app background and text    | Page shell, sections, body text            |
| `card` / `card-foreground`               | Elevated surfaces                  | Card, panels, settings sections            |
| `primary` / `primary-foreground`         | High-emphasis actions, brand color | Default Button, badges, active accents     |
| `secondary` / `secondary-foreground`     | Lower-emphasis actions             | Secondary buttons, supporting UI           |
| `muted` / `muted-foreground`             | Subtle surfaces, low-emphasis text | Placeholders, helper text, Input, Textarea |
| `accent` / `accent-foreground`           | Interactive highlights             | Ghost buttons, hover states                |
| `destructive` / `destructive-foreground` | Error and danger emphasis          | Destructive buttons, invalid states        |
| `border`                                 | Borders and separators             | Cards, menus, dividers                     |
| `input`                                  | Form control borders               | Input, Textarea, Select                    |
| `ring`                                   | Focus rings                        | Buttons, inputs, focusable controls        |

## Border Radius

| Token    | Purpose                             |
| -------- | ----------------------------------- |
| `radius` | Base corner radius (default: `8px`) |

Tailwind maps this to three utilities:

- `rounded-lg` → `var(--radius)` (8px)
- `rounded-md` → `calc(var(--radius) - 2px)` (6px)
- `rounded-sm` → `calc(var(--radius) - 4px)` (4px)

## Customizing Your Brand

Override any variable in `src/styles/default.css`:

```css title="src/styles/default.css"
page {
  /* Ocean blue brand */
  --primary: 210 100% 50%;
  --primary-foreground: 0 0% 100%;

  /* Warm card backgrounds */
  --card: 30 20% 98%;
  --card-foreground: 30 10% 10%;
}
```

Create a matching dark theme in `src/styles/dark.css` with inverted values.

## How the Tailwind Plugin Works

The `tailwind-plugin.ts` file (generated by `dolan init`) connects CSS variables to Tailwind color utilities. It enables opacity modifiers like `bg-primary/50`:

```typescript title="src/styles/tailwind-plugin.ts"
export const dolanPlugin = plugin(
  ({ addBase }) => {
    addBase({
      '*': { 'border-color': 'hsl(var(--border))' },
    });
  },
  {
    theme: {
      extend: {
        colors: {
          primary: {
            DEFAULT: 'hsl(var(--primary) / <alpha-value>)',
            foreground: 'hsl(var(--primary-foreground) / <alpha-value>)',
          },
          // ... all other tokens follow the same pattern
        },
      },
    },
  },
);
```
