# Typography

Nine text styles, from page headings to muted captions, that render as a single `<text>` element.

<Go example="ui-typography" defaultFile="src/app/app.ts" />

## Installation

```bash
npx @blotch/dolan add typography
```

```typescript
import { UiText } from '../components/ui/typography';
```

Typography imports `class-variance-authority` (see [Installation](/dolan/#installation)).

## Usage

```typescript title="src/app/app.ts"
import { Component } from '@angular/core';
import { UiText } from '../components/ui/typography';

@Component({
  selector: 'app-root',
  imports: [UiText],
  template: `
    <ui-text variant="h1">Order history</ui-text>
    <ui-text variant="muted">Updated a minute ago</ui-text>
  `,
})
export class App {}
```

`<ui-text>` wraps its content in a `<text>` element and sets the color for you, so the text follows your theme.

### Variants

| Variant | Classes                                  | Use for                 |
| ------- | ---------------------------------------- | ----------------------- |
| `h1`    | `text-4xl font-bold text-foreground`     | The page title          |
| `h2`    | `text-3xl font-semibold text-foreground` | Section titles          |
| `h3`    | `text-2xl font-semibold text-foreground` | Subsection titles       |
| `h4`    | `text-xl font-semibold text-foreground`  | Small headings          |
| `p`     | `text-base text-foreground`              | Body text (the default) |
| `lead`  | `text-xl text-muted-foreground`          | An intro paragraph      |
| `large` | `text-lg font-semibold text-foreground`  | Emphasized text         |
| `small` | `text-sm font-medium text-foreground`    | Labels and fine print   |
| `muted` | `text-sm text-muted-foreground`          | Captions and hints      |

### Custom classes

```angular-html
<ui-text variant="p" class="text-primary">Primary text</ui-text>
<ui-text variant="small" class="font-bold text-destructive">
  Payment failed
</ui-text>
```

Your classes replace the variant's classes where they conflict, so `text-primary` wins over `text-foreground`.

## API

### UiText

| Input     | Type                                                                             | Default | Description                          |
| --------- | -------------------------------------------------------------------------------- | ------- | ------------------------------------ |
| `variant` | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'p' \| 'lead' \| 'large' \| 'small' \| 'muted'` | `'p'`   | The text style.                      |
| `class`   | `string`                                                                         | `''`    | Extra Tailwind classes for the text. |

No outputs.

The file also exports `typographyVariants` and the `TypographyVariant` type.
