# Contact List

A searchable contact list grouped by first letter, with sticky letter headers, a contact dialog, an "Add Contact" form and a delete confirmation.

Built with the [UI components](/dolan/): [Avatar](/dolan/avatar), [Input](/dolan/input), [Dialog](/dolan/dialog), [Alert Dialog](/dolan/alert-dialog), [Empty State](/dolan/empty-state), [Separator](/dolan/separator), [Label](/dolan/label) and [Button](/dolan/button).

## What it shows

- **Search and grouping with `computed()`** — `filtered()` applies the query, and `grouped()` sorts the result and splits it by first letter.
- **Sticky section headers** — each letter header uses `sticky top-0` and is a direct child of the `<scroll-view>`. [Lynx](/guide/glossary#lynx) applies `position: sticky` only there. See [`<scroll-view>`](/api/elements/scroll-view).
- **Initials avatars** — an Avatar shows the initials from `initials()` when there's no photo.
- **Dialogs to view, add and delete** — tapping a contact opens a Dialog. Its Delete button hands off to an Alert Dialog to confirm.
- **An empty state** — an Empty State shows when no contacts match.
