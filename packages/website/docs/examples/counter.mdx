# Counter

A counter with increment, decrement and reset buttons, plus a label derived from the count. Look here for `computed()` and the UI components in a small app.

<Go example="counter" defaultFile="src/app/app.ts" />

## What it shows

- **`signal()` and `computed()`** — `label` recomputes whenever `count` changes. See [Signals and change detection](/guide/concepts/signals).
- **`update()` and `set()`** — the handlers change state, and Angular re-renders after each one.
- **UI components** — [Button](/dolan/button) and [Card](/dolan/card) from the [UI components](/dolan/). A button reports taps through its `(pressed)` output.
- **Flex layout** — the button row sets `display: flex` with the `flex flex-row` classes. Without it, [Lynx](/guide/glossary#lynx) stacks children vertically. See [CSS on Lynx](/guide/styling).
