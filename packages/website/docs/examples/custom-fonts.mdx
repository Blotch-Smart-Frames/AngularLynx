# Custom Fonts

Load and render custom fonts via `@font-face` in a Lynx application.

<Go example="custom-fonts" defaultFile="src/app/app.ts" />

## Key concepts

- **`@font-face`** — register custom fonts in a global CSS file, then reference them with `font-family` in inline styles or component styles
- **`font-family: Roboto`** — applies the custom font to any `<text>` element, falling back to the system font if unavailable
- **Font loading on Lynx** — custom fonts are bundled with the app and loaded by the native runtime, not fetched over the network like on the web
