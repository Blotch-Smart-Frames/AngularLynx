# Custom Fonts

Three font files registered with `@font-face`, shown next to the system font for comparison.

<Go example="custom-fonts" defaultFile="src/styles.css" />

## What it shows

- **`@font-face` in `src/styles.css`** — registers Roboto, Playfair Display and Dancing Script from the `.ttf` files in `src/assets/fonts`. See [Custom fonts](/guide/custom-fonts/).
- **`font-[Name]` classes** — Tailwind's arbitrary values, such as `font-[Roboto]`, set `font-family` on each `<text>`.
- **A system font baseline** — one card uses no custom font, so you can compare.
