# Error Handling

Throw an uncaught error from a tap handler and show the text AngularLynx saved for it on screen. On-screen errors help when no debugger is connected to the phone.

<Go example="error-handling" defaultFile="src/app/app.ts" />

## What it shows

- **An uncaught error** — the tap handler throws, and nothing catches it. Angular passes it to `LynxErrorHandler`, which `provideRenderer()` sets up. In [Lynx Explorer](/guide/glossary#lynx-explorer), Lynx's error screen opens. See [Handling errors](/guide/error-handling).
- **`__lynxLastError`** — a global where `LynxErrorHandler` saves the last uncaught error's name, message and stack as text. See [`LynxErrorHandler`](/api/angular-lynx/errors-and-logging).
- **Errors in a `<text>`** — a microtask, queued before the throw, copies the saved text into a signal once the handler has saved it. The screen shows it, or "(none)". See [Debugging](/guide/debugging).
