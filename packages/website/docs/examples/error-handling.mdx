# Error Handling

Catch an error in a tap handler and show its message and stack on screen. On-screen errors help when no debugger is connected to the phone.

<Go example="error-handling" defaultFile="src/app/app.ts" />

## What it shows

- **`try`/`catch` in a handler** — the error is caught, and its name, message and stack go into a signal.
- **`__lynxLastError`** — a global where AngularLynx's error handler writes the last uncaught error. The example writes its caught error there too. See [`LynxErrorHandler`](/api/angular-lynx/errors-and-logging).
- **Errors in a `<text>`** — the screen shows the saved text, or "(none)". See [Debugging](/guide/debugging).
