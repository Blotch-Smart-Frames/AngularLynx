# FAQ / Help Center

A searchable help page with collapsible categories, one answer open at a time and a "Contact Support" dialog.

Built with the [UI components](/dolan/): [Accordion](/dolan/accordion), [Collapsible](/dolan/collapsible), [Input](/dolan/input), [Dialog](/dolan/dialog), [Textarea](/dolan/textarea), [Label](/dolan/label) and [Button](/dolan/button).

<Go example="faq-help-center" defaultFile="src/app/app.ts" />

## What it shows

- **Search with `computed()`** — `filtered()` matches the query against questions and answers and drops empty categories. `@empty` shows a "no results" message.
- **Collapsible categories** — each category is a Collapsible that starts open, with `[open]="true"`.
- **One answer at a time** — an Accordion with `type="single"` closes the open answer when you open another.
- **A form in a dialog** — Contact Support opens a Dialog with a subject Input and a message Textarea.
