# Form Input

A profile form built from plain `<input>` and `<textarea>` elements, with focus styling and validation kept in signals. Use it to see the native input events without a forms library.

<Go example="form-input" defaultFile="src/app/app.ts" />

## What it shows

- **`(bindinput)`** — fires on every keystroke, with the new value in `$event.detail.value`. See [`<input>`](/api/elements/input).
- **`(bindfocus)` and `(bindblur)`** — track the focused field so its border can change color.
- **`confirm-type`** — sets the label of the on-screen keyboard's return key, here `next`.
- **`<textarea>`** — multi-line input with the same events. See [`<textarea>`](/api/elements/textarea).
- **Validation with `computed()`** — `validEmail` checks the address, and errors appear only after you tap Save Profile.
