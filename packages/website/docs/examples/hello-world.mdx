# Hello World

The smallest AngularLynx app: one signal, one tap handler and three [Lynx](/guide/glossary#lynx) elements. Start here to see what a template looks like.

<Go example="hello-world" defaultFile="src/app/app.ts" />

## What it shows

- **Lynx elements** — the template uses `<view>`, `<text>` and `<scroll-view>` instead of HTML, and text renders only inside `<text>`. See [Elements and layout](/guide/elements/).
- **`LYNX_ELEMENTS`** — the component imports it so the template type-checks. See [Elements](/api/angular-lynx/elements).
- **`(bindtap)`** — the tap event, the Lynx counterpart of `(click)`. See [Handling taps and events](/guide/elements/event-handling).
- **`signal()`** — the handler updates `count`, and the screen follows. See [Signals and change detection](/guide/concepts/signals).
