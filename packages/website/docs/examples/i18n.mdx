# Internationalization

Translatable strings with Angular's `i18n` attribute and `$localize`, plus the device locale from `LynxLocale`.

## What it shows

- **`i18n` attributes** — mark template text for translation, with custom IDs such as `@@app.greeting` and an optional meaning and description. See [Internationalization](/guide/i18n).
- **`$localize`** — marks strings in code, with named placeholders such as `${count}:count:`.
- **`LynxLocale`** — `locale()` is a signal with the locale the **host app** ([Glossary](/guide/glossary#host-app)) reports. Without one, it falls back to `sourceLocale` in `angular.json`. See [`LynxLocale`](/api/angular-lynx/locale).
- **`provideLocale()`** — in `app.config.ts`, it sets Angular's `LOCALE_ID` from that locale, so pipes format for it.
- **No translations yet** — the example ships no translation files, so it shows the source text.
