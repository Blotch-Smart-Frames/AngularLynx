# Examples

Self-contained examples you can copy into your project. Each one demonstrates a single AngularLynx feature with a complete, runnable component.

## Getting Started

| Example                      | What it covers                                 |
| ---------------------------- | ---------------------------------------------- |
| [Hello World](./hello-world) | Minimal counter with signals and event binding |
| [Counter](./counter)         | Signals, event binding, computed state         |
| [Todo List](./todo-list)     | `@for` control flow, dynamic lists, text input |
| [Form Input](./form-input)   | `<input>` / `<textarea>` with Lynx events      |
| [Forms](./forms)             | Reactive forms with validation                 |
