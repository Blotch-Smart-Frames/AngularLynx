# Examples

Small, complete AngularLynx apps, each focused on one feature or screen. Every example page runs the app live next to its source code.

## Using the previews

Each page embeds a live preview, which shows the code and the running app side by side:

- **Code** — the example's source, opened at its main file. Open **Files** to browse every file in the project.
- **Web** — runs the example in your browser through the web renderer of [Lynx](/guide/glossary#lynx). It's close to a phone, but not identical.
- **QR Code** — scan it with **Lynx Explorer** (Lynx's dev app for phones, see [Glossary](/guide/glossary#lynx-explorer)) to run the example on a real device.

The preview's footer names the example's folder, and its GitHub button opens that folder in the repository.

## Run an example locally

Every example is an Angular project in the repository's [`examples/`](https://github.com/Blotch-Smart-Frames/AngularLynx/tree/master/examples) folder. You need Node.js 22.12 or newer. Clone the repository, then start an example by its folder name:

```bash
git clone https://github.com/Blotch-Smart-Frames/AngularLynx.git
cd AngularLynx
npm install
npx turbo run start --filter=@angular-lynx-example/hello-world
```

- **Pick an example** — replace `hello-world` with the folder name from the preview's footer.
- **What the command does** — it builds the AngularLynx packages the example needs, then runs `ng serve`.
- **Open it** — `ng serve` prints a QR code for Lynx Explorer and a link to the **web preview** ([Glossary](/guide/glossary#web-preview)). See [Quick Start](/guide/quick-start).
