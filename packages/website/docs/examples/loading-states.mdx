# Loading States

A file manager that shows each kind of loading feedback: progress bars, skeleton rows, spinners and a toast when everything finishes.

Built with the [UI components](/dolan/): [Progress](/dolan/progress), [Skeleton](/dolan/skeleton), [Spinner](/dolan/spinner), [Toast](/dolan/toast), [Card](/dolan/card), [Badge](/dolan/badge), [Separator](/dolan/separator) and [Button](/dolan/button).

<Go example="loading-states" defaultFile="src/app/app.ts" />

## What it shows

- **Progress for known amounts** — each upload's Progress bar advances on a `setInterval`, and a Badge marks it done.
- **Skeletons while content loads** — Skeleton rows stand in for Recent Files for 1.5 seconds at startup, and again after Reload.
- **Spinners for unknown waits** — a Spinner appears next to "Syncing..." and inside the disabled upload Button.
- **A toast on completion** — `toast()` reports when every upload has finished.
