# Main-Thread Scripts

Touch handlers that restyle an element on every event, with no Angular re-render in between. Look here before you build drag- or scroll-driven effects.

<Go example="main-thread" defaultFile="src/app/app.ts" />

## What it shows

- **`mainThreadFn()`** — wraps a handler as a **main-thread script** ([Glossary](/guide/glossary#main-thread-script)) that edits the element directly with `setStyleProperty()`. See [`mainThreadFn`](/api/main-thread/main-thread-fn).
- **`[mainThreadBindtap]` and `[mainThreadBindtouchmove]`** — bind those handlers to an element's events. Import `LynxMainThreadEvent` to use them. See [`LynxMainThreadEvent`](/api/main-thread/main-thread-event).
- **`createMainThreadRef()`** — keeps the tap count between calls. See [`MainThreadRef`](/api/main-thread/main-thread-ref).
- **`backgroundFn()` and `runOnBackground()`** — call a function on the **background thread** ([Glossary](/guide/glossary#background-thread)) from a main-thread script. See [`backgroundFn`](/api/main-thread/background-fn).
- **A plain `(bindtap)` for comparison** — the third box updates a signal and lets Angular re-render. Use that for most handlers.
