# Media Player

A music player with playback controls, track progress, toggle buttons for shuffle/repeat, volume indicator, and a collapsible queue.

<Go example="media-player" defaultFile="src/app/app.ts" />

## Key concepts

- **Toggle for stateful controls** — `UiToggle` with `[(pressed)]` binding handles shuffle and repeat buttons that stay active when enabled
- **Progress for track position** — `UiProgress` shows current playback position; a `computed()` derives the timestamp display from the percentage
- **Collapsible for the queue** — `UiCollapsible` reveals or hides the "Up Next" track list, keeping the interface clean when not needed
- **Avatar for album art** — `UiAvatar` with a fallback character serves as a placeholder for album artwork at multiple sizes
