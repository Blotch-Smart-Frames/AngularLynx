# Notification Center

A notification feed with an unread count, long-press actions, toast confirmations and an empty state once everything is cleared.

Built with the [UI components](/dolan/): [Badge](/dolan/badge), [Card](/dolan/card), [Action Sheet](/dolan/action-sheet), [Toast](/dolan/toast), [Empty State](/dolan/empty-state) and [Button](/dolan/button).

## What it shows

- **Long press** — `(bindlongpress)` on each card opens an Action Sheet with Mark as Read and Delete. Event names need the `bind` or `catch` prefix; an unprefixed `(longpress)` is silently ignored. See [Handling taps and events](/guide/elements/event-handling).
- **Derived unread count** — `computed()` counts unread notifications for the header Badge, which hides at zero.
- **Toasts** — `toast({ title })` confirms each action, and one `<ui-toaster />` in the template displays them.
- **Empty state** — an Empty State replaces the list once it's empty.
