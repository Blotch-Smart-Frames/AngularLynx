# Onboarding Wizard

A four-step onboarding flow: a welcome screen, a role choice, multi-select interests and a summary.

Built with the [UI components](/dolan/): [Progress](/dolan/progress), [Radio Group](/dolan/radio-group), [Checkbox](/dolan/checkbox), [Card](/dolan/card), [Label](/dolan/label), [Separator](/dolan/separator) and [Button](/dolan/button).

<Go example="onboarding-wizard" defaultFile="src/app/app.ts" />

## What it shows

- **A step wizard** — `step()` and `@if` pick the visible panel, and `computed()` derives the Progress value.
- **Single choice** — a Radio Group with `[(value)]` picks one role.
- **Selectable cards** — each interest row is tappable and holds a Checkbox. A tap on the box bubbles up to the row, so only the row's `(bindtap)` toggles the interest. Class bindings highlight the selected rows.
- **A summary** — the last step lists the choices in a Card, with their names looked up by `computed()`.
