# Session Storage

A counter saved in session storage, which every page your app shows can read and write.

<Go example="session-storage" defaultFile="src/app/app.ts" />

## What it shows

- **`LynxSessionStorage`** — a key-value store that lasts while the [host app](/guide/glossary#host-app) runs and is shared between its pages. See [Share state between pages](/guide/session-storage).
- **`watch<number>('counter')`** — returns a signal that updates when the key changes.
- **`setItem()`** — stores a value. Values can be numbers or objects, not only strings.
- **`getItem()`** — a one-time read that returns a promise. The example shows "(not available)" if it fails.
