# Settings Page

A settings screen with grouped switches, a language picker, a theme choice and a confirmed "Delete Account" button. Use it as a starting point for your own preferences screen.

Built with the [UI components](/dolan/): [Switch](/dolan/switch), [Select](/dolan/select), [Radio Group](/dolan/radio-group), [Alert Dialog](/dolan/alert-dialog), [Button](/dolan/button), [Label](/dolan/label) and [Separator](/dolan/separator).

## What it shows

- **Two-way binding to signals** — `[(checked)]`, `[(value)]` and `[(open)]` bind each control straight to a `signal`. See [Signals and change detection](/guide/concepts/signals).
- **Grouped sections** — headings and separators split the screen into Notifications, Appearance and Danger Zone.
- **Tappable radio labels** — each label sits inside its `ui-radio-group-item`, so tapping the text selects the option. [Lynx](/guide/glossary#lynx) has no `<label for>`.
- **Confirming a destructive action** — Delete Account opens an Alert Dialog with Cancel and Delete buttons.
- **A stored theme choice** — the theme radio group only saves the choice in a signal. To switch colors, see [Dark mode](/guide/dark-mode).
