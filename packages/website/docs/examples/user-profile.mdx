# User Profile

A profile screen with an avatar, a badge, stats and an "About" card, plus a sheet for editing the bio. Look here for a view-then-edit screen.

Built with the [UI components](/dolan/): [Avatar](/dolan/avatar), [Badge](/dolan/badge), [Card](/dolan/card), [Sheet](/dolan/sheet), [Input](/dolan/input), [Textarea](/dolan/textarea), [Label](/dolan/label), [Separator](/dolan/separator) and [Button](/dolan/button).

## What it shows

- **Avatar fallback** — `[fallback]="initials()"` shows initials when there's no photo. `initials` is a `computed()` from the saved name.
- **Vertical separators** — `orientation="vertical"` divides the Posts, Followers and Following stats.
- **Editing in a sheet** — Edit Profile opens a Sheet that slides up from the bottom, so there's no navigation to a new screen.
- **Draft, then save** — the sheet edits copies in `editName` and `editBio`. Save copies them into `name` and `bio`, and Cancel closes the sheet without saving. Opening the sheet starts again from the saved values.
- **Card sections** — a Card with a header and content groups the About text.
