# Programmatic animate() API

For imperative control, use the `animate()` method on native Lynx elements. Access the element via `viewChild` and call `animate()` with keyframes and options:

```typescript title="src/app/pulse.ts"
import { Component, viewChild, type ElementRef } from '@angular/core';
import { LYNX_ELEMENTS, type LynxAnimation } from '@blotch/angular-lynx'; // [!code highlight]

@Component({
  imports: [LYNX_ELEMENTS],
  template: `
    <view #box class="box" (bindtap)="runAnimation()">
      <text>Tap to pulse</text>
    </view>
  `,
  styles: [
    `
      .box {
        width: 100px;
        height: 100px;
        background-color: #6200ee;
        align-items: center;
        justify-content: center;
      }
    `,
  ],
})
export class Pulse {
  readonly boxRef = viewChild<ElementRef>('box');
  #animation: LynxAnimation | null = null;

  runAnimation(): void {
    setTimeout(() => {
      const el = this.boxRef();
      if (!el) return;

      this.#animation?.cancel(); // [!code highlight]

      this.#animation = el.nativeElement.animate(
        // [!code highlight]
        [
          // [!code highlight]
          { transform: 'scale(1)', opacity: 1 }, // [!code highlight]
          { transform: 'scale(1.3)', opacity: 0.7 }, // [!code highlight]
          { transform: 'scale(1)', opacity: 1 }, // [!code highlight]
        ], // [!code highlight]
        { duration: 600, easing: 'ease-in-out' }, // [!code highlight]
      ); // [!code highlight]
    }, 0);
  }
}
```

:::tip
Always cancel the previous animation before starting a new one on the same element to prevent stacking.
:::

## LynxAnimation

`element.animate()` returns a `LynxAnimation` object:

| Method     | Description                                 |
| ---------- | ------------------------------------------- |
| `play()`   | Resume a paused animation                   |
| `pause()`  | Pause the animation at its current position |
| `cancel()` | Stop and remove the animation               |

## LynxAnimationOptions

| Option                          | Type               | Description                                                 |
| ------------------------------- | ------------------ | ----------------------------------------------------------- |
| `duration`                      | `number \| string` | Duration in milliseconds                                    |
| `delay`                         | `number \| string` | Delay before animation starts                               |
| `easing` / `timingFunction`     | `string`           | Timing function (e.g., `'ease-in-out'`, `'linear'`)         |
| `iterations` / `iterationCount` | `number \| string` | Number of repetitions (`Infinity` for loop)                 |
| `fill` / `fillMode`             | `string`           | Fill mode (`'forwards'`, `'backwards'`, `'both'`, `'none'`) |
| `direction`                     | `string`           | Direction (`'normal'`, `'reverse'`, `'alternate'`)          |

Both Web Animations API naming (`easing`, `iterations`, `fill`) and Lynx-native naming (`timingFunction`, `iterationCount`, `fillMode`) are accepted.
