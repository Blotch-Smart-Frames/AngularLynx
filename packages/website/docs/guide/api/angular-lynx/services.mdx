# Services

## Accessibility

| Export              | Kind       | Description                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxAccessibility` | Injectable | Programmatic accessibility control for screen readers. Methods: `announce(content): Promise<void>` (makes screen readers speak the text via `lynx.accessibilityAnnounce`), `requestFocus(selector): Promise<void>` (moves accessibility focus to an element via `createSelectorQuery().select(selector).invoke({ method: 'requestAccessibilityFocus' })`). Rejects if `lynx` is unavailable. |

## Data & State

| Export           | Kind       | Description                                                                                                                                                                                                            |
| ---------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxInitData`   | Injectable | Reactive wrapper for `lynx.__initData` — data passed from the native host to the LynxView at launch. Exposes a `initData` signal that updates automatically when the native host calls `updateData()`.                 |
| `LynxGlobalData` | Injectable | Reactive wrapper for `lynx.__globalProps` — app-wide properties set by the native host. Exposes a `globalData` signal that updates automatically when the native host changes global props via `onGlobalPropsChanged`. |

## Session Storage

| Export                       | Kind       | Description                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `LynxSessionStorage`         | Injectable | Cross-LynxView key-value store backed by `lynx.setSessionStorageItem` / `getSessionStorageItem`. Values are objects (not strings). Methods: `setItem(key, value)`, `getItem<T>(key): Promise<T>`, `subscribe(key, cb)`, `unsubscribe(sub)`, `watch<T>(key): Signal<T \| undefined>`. Falls back to an in-memory map outside the Lynx runtime (web preview, tests). |
| `SessionStorageSubscription` | Type       | Opaque handle returned by `LynxSessionStorage.subscribe()`. Pass to `unsubscribe()` to cancel the subscription.                                                                                                                                                                                                                                                    |

## Visibility & Exposure

| Export                | Kind       | Description                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxGlobalExposure`  | Injectable | Global viewport visibility tracker. Listens to batched `exposure` / `disexposure` events from `lynx.GlobalEventEmitter` (~20 fps). Exposes `exposures` and `disexposures` signals (arrays of `ExposureEventDetail`), an `active` signal, and `stopExposure()` / `resumeExposure()` / `setObserverFrameRate()` methods. Requires elements to have an `exposure-id` attribute set. |
| `LynxExposure`        | Directive  | `[lynxExposure]` — per-element visibility directive. Attaches `binduiappear` / `binduidisappear` native event listeners and exposes a `visible` signal. Use `exportAs="lynxExposure"` to read the signal in the template: `<view lynxExposure #exp="lynxExposure">`. Works independently of `LynxGlobalExposure`.                                                                |
| `GlobalExposureEvent` | Type       | Array of `ExposureEventDetail` — the payload emitted by `LynxGlobalExposure.exposures` and `disexposures` signals.                                                                                                                                                                                                                                                               |
| `ExposureEventDetail` | Type       | A single entry in a `GlobalExposureEvent` batch. Contains `exposureID`, `exposureScene`, and their kebab-case equivalents (`exposure-id`, `exposure-scene`) plus a `unique-id` number.                                                                                                                                                                                           |

## Main Thread

| Export               | Kind       | Description                                                                                                                                                                                                                                                                   |
| -------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxMainThread`     | Injectable | Runs a registered main-thread worklet from the background thread. Call `runOnMainThread(handle, ...args): Promise<TReturn>`. Arguments must be JSON-serializable. Throws if called from the main thread. In dev mode, also validates argument serializability.                |
| `mainThreadFn`       | Function   | Registers a function as a main-thread worklet and returns a `MainThreadFnHandle`. Both thread bundles call `mainThreadFn` in the same module evaluation order, so IDs stay in sync without a compiler plugin. Pass the returned handle to `LynxMainThread.runOnMainThread()`. |
| `MainThreadFnHandle` | Type       | Opaque handle returned by `mainThreadFn`. Carries phantom `TArgs` / `TReturn` types for call-site type checking. Only the `_wkltId` field is used at runtime.                                                                                                                 |

## Fonts

| Export               | Kind       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxFont`           | Injectable | Dynamically loads fonts via `lynx.addFont()`. Use CSS `@font-face` in stylesheets for fonts known at build time; use this service only for fonts determined at runtime. Methods: `addFont(config): Promise<void>`, `isLoaded(family): boolean`, `getStatus(family): LynxFontStatus`. Reactive signals: `fonts` (map of all registered entries) and `loadedFamilies` (computed set of successfully loaded family names). Deduplicates concurrent load requests for the same family. |
| `LynxFontFaceConfig` | Type       | Config for `addFont()`. Fields: `fontFamily: string`, `src: string`.                                                                                                                                                                                                                                                                                                                                                                                                               |
| `LynxFontStatus`     | Type       | `'idle' \| 'loading' \| 'loaded' \| 'error'` — the loading state of a registered font family.                                                                                                                                                                                                                                                                                                                                                                                      |
| `LynxFontEntry`      | Type       | A font registry entry. Contains `fontFamily`, `src`, `status`, and an optional `error` field when `status === 'error'`.                                                                                                                                                                                                                                                                                                                                                            |

## System Info

| Export           | Kind       | Description                                                                                                                                                                                                                                                                                                                                       |
| ---------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxSystemInfo` | Injectable | Wraps the global `SystemInfo` object. Properties: `platform`, `engineVersion`, `osVersion`, `pixelWidth`, `pixelHeight`, `pixelRatio`, `runtimeType`, `theme`. Computed: `screenWidth` and `screenHeight` (logical/CSS pixels derived from physical pixels ÷ pixel ratio). Throws if `SystemInfo` is unavailable (e.g. outside the Lynx runtime). |

## Resource Prefetching

| Export                 | Kind       | Description                                                                                                                                                                                                                                                                                                                          |
| ---------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `LynxResourcePrefetch` | Injectable | Preloads images and videos into the native cache via `lynx.requestResourcePrefetch()` / `lynx.cancelResourcePrefetch()`. Methods: `request(resources): Promise`, `cancel(resources): Promise`. Each resource specifies `uri` and `type` (`'image'` or `'video'`), with optional `priority`, `cacheTarget`, `preloadKey`, and `size`. |
| `PrefetchRequest`      | Type       | Describes a resource to prefetch. Fields: `uri: string`, `type: 'image' \| 'video'`, optional `priority: 'high' \| 'medium' \| 'low'`, `cacheTarget: 'disk' \| 'bitmap'`, `preloadKey: string`, `size: number`.                                                                                                                      |

## Text Measurement

| Export            | Kind       | Description                                                                                                                                                                                                                               |
| ----------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxTextMeasure` | Injectable | Measures text dimensions via `lynx.getTextInfo()`. Method: `measure(text: string, options: TextInfo): TextMetrics`. Returns `{ width, content? }`. Only accurate for built-in platform fonts — custom fonts fall back to the system font. |

## Portal / Overlay

| Export         | Kind       | Description                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxPortal`   | Injectable | Programmatically renders Angular components or templates inside a native `<overlay>` element — the equivalent of Angular CDK's `Overlay` / `DomPortalOutlet`. For declarative overlays, use `<overlay>` directly in your template. Methods: `open<T>(component, config?): PortalRef<T>` (creates overlay + renders component), `openTemplate(template, config?): PortalRef<null>` (creates overlay + renders template). |
| `PortalRef<T>` | Class      | Handle for a portal instance. Properties: `instance: T \| null` (component instance, null for template portals). Methods: `setInput(name, value)` (update component inputs), `destroy()` (tear down overlay, detach from change detection, destroy component/view).                                                                                                                                                     |
| `PortalConfig` | Type       | Configuration for portal creation. Fields: `level?: number` (overlay z-level, 1–4), `injector?: EnvironmentInjector` (custom DI context), `inputs?: Record<string, unknown>` (initial component inputs).                                                                                                                                                                                                                |

## Native Modules

| Export             | Kind       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------ | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxNativeModule` | Injectable | Bridge to native platform code and JS module sharing within a LynxView. Methods: `call<T>(name, params?): Promise<T>` (wraps `NativeModules.bridge.call`), `on(name, cb)` (native events via `bridge.on`), `getNativeModule<K>(name): T` (typed access to custom native modules), `getJSModule<T>(name)` (wraps `lynx.getJSModule`), `registerJSModule(name, module)` (wraps `lynx.registerModule`). Graceful no-ops outside the Lynx runtime. |
| `NativeModuleMap`  | Type       | Extensible interface for typing custom native modules. Augment via `declare module '@blotch/angular-lynx' { interface NativeModuleMap { MyModule: { ... } } }` for type-safe `getNativeModule()` calls.                                                                                                                                                                                                                                        |

## Locale / i18n

| Export          | Kind       | Description                                                                                                                                                                                                                                                                                       |
| --------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxLocale`    | Injectable | Reactive wrapper for the current locale. Reads `lynx.__globalProps.appLocale` via `LynxGlobalData`; falls back to the compile-time `__LYNX_SOURCE_LOCALE__` constant (from angular.json `i18n.sourceLocale`), then to `'en-US'`. Exposes a `locale` signal that updates when global props change. |
| `provideLocale` | Function   | Returns `EnvironmentProviders` that sets Angular's `LOCALE_ID` injection token from `LynxLocale.locale()`. Add to your `bootstrapApplication` providers alongside `provideRenderer()` to configure locale-aware pipes and `$localize` formatting.                                                 |

## Error Handling & Logging

| Export             | Kind       | Description                                                                                                                                                                                                                                                                                             |
| ------------------ | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxErrorHandler` | Injectable | Angular `ErrorHandler` that routes unhandled errors to the native Lynx error reporting API (`_ReportError` with error code 1101). Also writes the formatted error to `globalThis.__lynxLastError` so it can be surfaced via `<text>` elements on device. Automatically provided by `provideRenderer()`. |
| `LynxLogger`       | Injectable | Remote logging service — sends log calls from on-device to the rspeedy dev server via `fetch()` so they appear in the developer's terminal. Methods: `log()`, `warn()`, `error()`, `info()`, `debug()`. All methods are no-ops in production.                                                           |
