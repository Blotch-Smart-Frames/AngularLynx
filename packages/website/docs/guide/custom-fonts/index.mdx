# Custom fonts

Set text in your own typeface. Declare a font with `@font-face` when its file ships with your app, or load it while the app runs with `LynxFont.addFont()`.

<Go example="custom-fonts" defaultFile="src/app/app.ts" />

## Choose an approach

| Approach             | Use it when                                                          | Works in the web preview |
| -------------------- | -------------------------------------------------------------------- | ------------------------ |
| `@font-face`         | The font file is in your project                                     | Yes                      |
| `LynxFont.addFont()` | The font comes from a URL, or depends on a setting chosen at runtime | No                       |

Prefer `@font-face`. The font becomes part of the [bundle](/guide/glossary#bundle), so it loads with the app and needs no network.

## Declare a font with `@font-face`

Put the font file in `src/assets/fonts/`, then declare it in your global stylesheet:

```css title="src/styles.css"
@font-face {
  font-family: 'Roboto';
  src: url('./assets/fonts/Roboto-Light.ttf') format('truetype');
}
```

Use the family on each `<text>` that needs it:

```typescript title="src/app/heading.ts"
import { Component } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';

@Component({
  selector: 'app-heading',
  imports: [LYNX_ELEMENTS],
  template: `<text class="app-heading">Hello in Roboto</text>`,
  styles: `
    .app-heading {
      font-family: Roboto;
      font-size: 24px;
    }
  `,
})
export class Heading {}
```

- **Set `font-family` on the `<text>` itself.** Fonts don't inherit from a `<view>` on Lynx. A nested `<text>` does take its parent's family. See [Inheritance](/guide/styling#inheritance).
- **With Tailwind**, use an arbitrary value: `class="font-[Roboto]"`.
- **The build embeds the font in the bundle** as Base64. That's why it loads on any device and in the web preview, with no fetch. Each font adds about 1.3 times its file size to the bundle, so keep font files small.

### One family name per weight

`@font-face` accepts only the `font-family` and `src` descriptors. Lynx ignores `font-weight`, `font-style`, `font-display` and `unicode-range`, so you can't put two weights under one name. Give each its own family:

```css title="src/styles.css"
@font-face {
  font-family: 'Inter-Regular';
  src: url('./assets/fonts/Inter-Regular.ttf') format('truetype');
}

@font-face {
  font-family: 'Inter-Bold';
  src: url('./assets/fonts/Inter-Bold.ttf') format('truetype');
}
```

A variable font is the other way to get several weights from one family.

### File formats

| Platform | Formats               |
| -------- | --------------------- |
| iOS      | TTF, OTF, WOFF, WOFF2 |
| Android  | TTF, OTF, TTC         |

Use TTF or OTF to cover both.

## Load a font at runtime

Inject `LynxFont` and call `addFont()` when a component starts:

```typescript title="src/app/greeting.ts"
import { Component, inject } from '@angular/core';
import { LYNX_ELEMENTS, LynxFont } from '@blotch/angular-lynx';

@Component({
  selector: 'app-greeting',
  imports: [LYNX_ELEMENTS],
  template: `<text style="font-family: Lobster">Hello in Lobster</text>`,
})
export class Greeting {
  readonly #fonts = inject(LynxFont);

  constructor() {
    this.#fonts
      .addFont({
        fontFamily: 'Lobster',
        src: 'url("https://example.com/fonts/Lobster-Regular.ttf")',
      })
      .catch(() => {
        // The web preview can't load fonts at runtime. See below.
      });
  }
}
```

- **Call it from anywhere,** including a tap handler. Lynx accepts `addFont()` only on the [background thread](/guide/glossary#background-thread), so AngularLynx sends calls from the main thread there.
- **Text switches when the font arrives.** Until then, text that names the family shows the system font.
- **Write `src` as a CSS `url()`**, the same value you'd put in `@font-face`.
- **Repeat calls are safe.** A second call for the same family returns the same promise.

### Limitations of runtime fonts

- **Not in the web preview.** Lynx's web renderer doesn't load fonts at runtime. Test them on a phone.

## Limitations

- **One weight per family name**, as described above.
- **Text measurement ignores custom fonts.** [`LynxTextMeasure`](/guide/text-measurement) measures with the platform's built-in fonts.
