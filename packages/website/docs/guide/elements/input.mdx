# &lt;input&gt;

:::tip
Add `imports: [LYNX_ELEMENTS]` from `@blotch/angular-lynx` to your component for intellisense, autocomplete, and type safety.
:::

Single-line text input field.

<Go example="element-input" defaultFile="src/app/app.ts" />

```angular-html
<input
  type="text"
  placeholder="Enter your name"
  (bindinput)="onInput($event)"
/>
```

The input event provides the value via `event.detail.value`:

```typescript
onInput(event: { detail: { value: string } }): void {
  this.name.set(event.detail.value);
}
```

## Key Attributes

| Attribute     | Type      | Description                                              |
| ------------- | --------- | -------------------------------------------------------- |
| `type`        | `string`  | Input type: `"text"` (default), `"number"`, `"password"` |
| `placeholder` | `string`  | Placeholder text shown when empty                        |
| `maxlength`   | `number`  | Maximum character length                                 |
| `auto-focus`  | `boolean` | Automatically focus when the element appears             |
| `value`       | `string`  | Current input value                                      |

## Events

| Event         | Description                                                              |
| ------------- | ------------------------------------------------------------------------ |
| `bindinput`   | Fires on every keystroke. `event.detail.value` contains the current text |
| `bindfocus`   | Fires when the input gains focus                                         |
| `bindblur`    | Fires when the input loses focus                                         |
| `bindconfirm` | Fires when the user presses the confirm/return key                       |

For form patterns with validation, see the [Forms](/guide/forms) guide.
