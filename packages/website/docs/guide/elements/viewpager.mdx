# &lt;viewpager&gt;

:::tip
Add `imports: [LYNX_ELEMENTS]` from `@blotch/angular-lynx` to your component for intellisense, autocomplete, and type safety.
:::

A horizontally swipeable paging container. Each page is a `<viewpager-item>` child. The native gesture recognizer handles swipe navigation.

```angular-html
<viewpager
  [attr.initial-select-index]="0"
  (bindchange)="onPageChange($event)"
  style="width: 100%; height: 300px;"
>
  <viewpager-item style="align-items: center; justify-content: center;">
    <text style="font-size: 24px;">Page 1</text>
  </viewpager-item>
  <viewpager-item style="align-items: center; justify-content: center;">
    <text style="font-size: 24px;">Page 2</text>
  </viewpager-item>
  <viewpager-item style="align-items: center; justify-content: center;">
    <text style="font-size: 24px;">Page 3</text>
  </viewpager-item>
</viewpager>
```

## Key Attributes

- `initial-select-index` — (number, default `0`) Page index to display on first render
- `enable-scroll` — (boolean, default `true`) Whether the horizontal swipe gesture is enabled
- `bounces` — (boolean, default `true`) Whether the pager bounces past the edge pages (iOS/Harmony/Clay)
- `keep-item-view` — (boolean, default `false`) Keep all page views in memory; disables lazy creation

### Platform-specific

- `android-always-overscroll` — (boolean, default `false`) Enable bounce at edges on Android
- `android-force-can-scroll` — (boolean, default `false`) Block gesture pass-through to parent on Android
- `ios-gesture-direction` — (boolean, default `false`) Allow outer container swipe at edge pages on iOS
- `ios-gesture-offset` — (number, default `0`) Left-edge exclusion zone (px) for swipe gesture on iOS
- `ios-recognized-gesture-class` — (`string`) UIGestureRecognizer class name for simultaneous recognition on iOS
- `ios-recognized-view-tag` — (number, default `0`) UIView tag for simultaneous gesture recognition on iOS

## Events

- `(bindchange)` — Fired after the page settles on a new index. Detail: `{ current: number }`
- `(bindoffsetchange)` — Fired continuously during a swipe. Detail: `{ offset: number }` (fractional page offset)
- `(bindwillchange)` — Fired before a page transition starts. Detail: `{ current: number, target: number }`

## Children

**`<viewpager-item>`** — Each direct child must be a `<viewpager-item>`. Content inside is laid out at 100% width and 100% height of the pager.

## Dynamic Pages with `@for`

```angular-html
<viewpager
  [attr.initial-select-index]="currentPage()"
  (bindchange)="currentPage.set($event.detail.current)"
  style="width: 100%; height: 100%;"
>
  @for (slide of slides(); track slide.id) {
    <viewpager-item>
      <image [attr.src]="slide.imageUrl" style="width: 100%; height: 100%;" />
    </viewpager-item>
  }
</viewpager>
```

## Page Indicator

Combine `(bindchange)` with a signal to drive a custom dot indicator:

```typescript
currentPage = signal(0);
```

```angular-html
<view style="flex-direction: column; flex: 1;">
  <viewpager
    (bindchange)="currentPage.set($event.detail.current)"
    style="flex: 1;"
  >
    @for (slide of slides(); track slide.id) {
      <viewpager-item>
        <text>{{ slide.title }}</text>
      </viewpager-item>
    }
  </viewpager>

  <!-- Dot indicator -->
  <view style="flex-direction: row; justify-content: center; padding: 8px;">
    @for (slide of slides(); track slide.id; let i = $index) {
      <view
        style="width: 8px; height: 8px; border-radius: 4px; margin: 4px;"
        [style.background-color]="i === currentPage() ? '#333' : '#ccc'"
      />
    }
  </view>
</view>
```
