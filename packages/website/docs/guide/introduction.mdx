# What is AngularLynx?

**AngularLynx lets you build iOS and Android apps with Angular.** You write components, signals and templates as usual. Your app renders as real native mobile UI, not as a web page inside an app.

## What is Lynx?

[**Lynx**](https://lynxjs.org/) is an open-source engine for building mobile apps with JavaScript and CSS. ByteDance built it, uses it in TikTok, and open-sourced it in 2025.

Lynx turns a tree of **elements** into the phone's own UI controls, the same ones a Swift or Kotlin app uses. You style those elements with CSS. Lynx draws them on iOS, Android and the web from one codebase.

Lynx doesn't decide how you write your app. A **framework** sits on top and creates the elements. Lynx's own framework is React-based. AngularLynx is the Angular one.

## What AngularLynx gives you

- **Angular on Lynx.** Standalone components, signals, dependency injection, the router, forms, pipes, `@if`/`@for` and `@defer` all work. Templates use Lynx elements such as `<view>` and `<text>` instead of HTML.
- **The Angular CLI.** `ng serve` previews your app in the browser and on your phone. `ng build --platform ios` or `--platform android` builds an app you can install or upload. `ng test` runs your tests, and `ng generate component` makes Lynx components.
- **UI components.** [Buttons, dialogs, forms, charts and more](/dolan/) that you copy into your project and own.
- **A testing library** that renders your components in Vitest.

## What you need to know

| You need                                      | You don't need                               |
| --------------------------------------------- | -------------------------------------------- |
| TypeScript and CSS                            | Swift, Kotlin, Objective-C or Java           |
| Some Angular (components, signals, templates) | To create or edit an Xcode or Gradle project |
| Node.js on your computer                      | A Mac, unless you build the iOS app          |

To build installable apps, you do install Apple's and Google's build tools: Xcode for iOS and Android Studio for Android. AngularLynx drives them for you. [Run on iOS and Android](/guide/native-apps) shows how.

## How it compares

Several tools let web developers build mobile apps. They differ mostly in what ends up on screen.

<ToolCompare />

**Choose a WebView tool** if you need the full browser: the DOM, every web library and every CSS feature.

**Choose a native-controls tool** if you want the app to look and feel like other apps on the phone. AngularLynx is for Angular developers in that second group.

## How it's different from Angular on the web

Most of your Angular knowledge carries over. Four things change:

1. **No HTML.** Use `<view>` instead of `<div>` and `<text>` instead of `<span>`. Text only shows inside `<text>`.
2. **Different events.** `(bindtap)` replaces `(click)`.
3. **A different CSS engine.** Most layout CSS works, but some features don't, such as `:hover` and `@media`.
4. **No browser.** There's no `document`, `window` or DOM API, so libraries that touch the DOM don't work.

[Coming from web Angular](/guide/coming-from-web) lists every difference, with a table of which Angular features work.

## Project status

:::warning Work in progress
AngularLynx is an early proof of concept. Real apps are possible: components, signals, routing, forms, gestures, animations and native app builds work. Some APIs are missing, and APIs may change between releases.
:::

AngularLynx targets Angular 22. Report problems on [GitHub](https://github.com/Blotch-Smart-Frames/AngularLynx/issues).
