# Event Reference

All events supported by `fireEvent` in `@blotch/angular-lynx-testing-library`. Each event maps to a `(bindEvent)` template binding.

## Touch / Gesture

| Event         | Template binding    |
| ------------- | ------------------- |
| `tap`         | `(bindtap)`         |
| `longtap`     | `(bindlongtap)`     |
| `touchstart`  | `(bindtouchstart)`  |
| `touchmove`   | `(bindtouchmove)`   |
| `touchcancel` | `(bindtouchcancel)` |
| `touchend`    | `(bindtouchend)`    |
| `longpress`   | `(bindlongpress)`   |

## Keyboard

| Event     | Template binding |

| `keyup`   | `(bindkeyup)`    |

## Raw Event Dispatch

For events not in the table, dispatch directly:

```ts
fireEvent(element, new Event('bindEvent:myCustomEvent'));
```
